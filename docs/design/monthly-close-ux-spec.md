## 0. 이 문서의 요약

### 0-1. 방향서를 그대로 따른 것 (뒤집지 않음)
8×8 / 3척(4·3·2) / 먼저 2척 침몰 / 분할 창 2개(창마다 머리글, 판은 A1:H8) / Tab·Shift+Tab·ESC는 숨기기 전용·복귀는 게임 시트 탭 클릭 / 창 이탈 시 숨기고 돌아와도 유지 / 클릭은 선택, Enter·같은 칸 다시 클릭·더블클릭이 발사 / 검산 10초·오답 `#VALUE!` 3초 잠금 / 검산 동안 발사 시계 정지 / 힌트 보유형(판당 받은 2개) / 결재 경보 3초 / 도발 공통 10개·3회차 간격 / 종료 후 상대 배치 공개 / 홈은 숨기기 없음 / 베타 표기는 홈·입장 대화상자·결과 문서 꼬리만 / 용어 사전(방→문서, 배→항목 …).

### 0-2. 이 문서에서 보충해 정한 UX 결정 (방향서가 비워 둔 곳)

| # | 결정 | 이유 |
|---|---|---|
| U1 | **양식(업종)·닉네임·결재 경보 포함 여부는 홈에서 정한다.** 번호로 입장할 때도 홈의 값을 쓴다. 링크로 들어온 사람만 입장 대화상자에서 정한다 | 방장 3탭(홈 → 만들기 → 배치) 유지. 기본값은 "마지막에 쓴 양식 / 회계, 닉네임 `편집자NN`, 경보 켬" |
| U2 | **이름 상자에서 좌표를 치고 Enter = 바로 발사.** 칸 클릭은 선택만, 다시 클릭·Enter·더블클릭·✓ 버튼이 발사 | 이름 상자 입력은 의도가 분명한 행동이다. 한 번 더 Enter를 요구하면 쏜 사람의 손만 느려진다 |
| U3 | **수식 입력줄의 ✓ / ✕ 버튼이 마우스용 확정·취소다.** 힌트 범위 고르기·배치 범위 확정에도 같은 버튼을 쓴다 | ESC가 숨기기라서 "ESC로 취소"가 불가능하다. 취소 수단이 화면 안에 보여야 한다 |
| U4 | **숨기면 모든 임시 모드(힌트 고르기, 열린 드롭다운, 열린 팝오버, 공유 패널)가 취소된다.** 선택된 칸·검산 입력값·배치 초안은 유지 | 위장 시트 위에 게임 요소가 남으면 안 된다(등급 0). 데이터는 지우지 않는다 |
| U5 | **확인 창은 전부 "시트 안 팝오버"다.** `alert/confirm/<dialog>` 금지(방향서 §8-2 #12). 나가기·기권·부재 처리는 팝오버 2버튼 | 네이티브 창은 숨기기와 함께 사라지지 않는다 |
| U6 | **결과 탭은 자동으로 열리지 않는다.** 종료 순간에는 판에 상대 항목이 공개되고(감정의 정점), 토스트 "문서 1건이 생성되었습니다 [열기]"가 남는다 | 상대 배치를 보여 준 뒤 문서로 넘어가야 "아, 거기였어?"가 산다. 화면 전체 연출 금지와도 맞다 |
| U7 | **`비고` 탭과 `[+]`도 숨기기 시트로 간다.** `손익`(숨기기)과 `비고`(장식)는 같은 업종 데이터의 다른 시트이고, 비고는 10행 안팎의 단순 메모형이다 | 장식 탭을 눌러도 숨기기가 되게 하려면 보여 줄 시트가 필요하다 |
| U8 | **숨겨 있는 동안 게임 단서는 0개.** "내 차례다/경보가 지났다/상대가 돌아왔다" 어떤 표시도 숨기기 시트에 없다. 돌아오면 상태줄에 "무슨 일이 있었는지" 1줄을 5초 보인다 | 등급 0 규칙. 단서(점·제목·소리)는 그 자체가 티다. 대신 복귀 시 요약으로 보완 |
| U9 | **키보드 접근 대안 3가지**: ① 방향키로 칸 이동, Enter 발사 ② 칸에서 `A~H`·`ㅁ~ㅗ`를 치면 이름 상자로 자동 이동(스프레드시트에서 칸에 글자를 치면 편집이 시작되는 것과 같은 문법) ③ **F10 = 도구줄 이동 모드**(←→ 이동, Enter 실행, ↓ 또는 도구줄 밖 클릭으로 격자 복귀). F10이 브라우저와 충돌하면 대체 키를 [요청] | Tab이 막혀도 버튼(Σ, 의견 남기기, 자동 배치 …)에 닿아야 한다(WCAG 2.1.1) |
| U10 | **도움말 > 인수인계서(규칙)와 파일 > 문서 닫기 두 메뉴만 실제로 동작**한다. 나머지 메뉴·아이콘은 장식 | 규칙 재확인과 나가기 동선이 없으면 막힌다 |
| U11 | **검산 표는 오른쪽 창 10~13행 4줄**(제목 / 머리글 / 값 / 입력)을 쓴다. 팀장 안의 10~14행 중 14행은 비운다 | 정답이 1셀이라 4줄이면 충분하고, 1366×768에서도 스크롤이 없다 |
| U12 | **힌트 결과 위치**: 열 → 오른쪽 창 9행의 그 열, 행 → 오른쪽 창 I열의 그 행, 3×3 → 오른쪽 창 15행 이후 "검토 의견" 표. 상대가 내 판을 조회한 기록은 왼쪽 창 15행 이후 "변경 내역"(값 없이 범위만) | [방향서·팀장 안] 그대로 |
| U13 | **종료 이유 문구 4종을 공통 묶음에 추가**(정상·상대 이탈·부재 처리·30회차 상한) | 결과 문서가 이유 없이 승패만 말하면 기권승이 어색하다 |
| U14 | **`{상대}` 토큰은 닉네임 앞 4자**로 줄여 쓴다 | 닉네임 8자 + 문장이 28자 상한을 넘지 않게 한다 |

## 1. 사용자 페르소나

| | **P1 · 방장 "점심 내기 기획자"** | **P2 · 초대받은 사람 "링크 클릭러"** | **P3 · 경계하는 사람 "눈치 빠른 사무직"** |
|---|---|---|---|
| 상황 | 사무실 PC(1366×768 노트북 비중 큼), 점심 후 10분. 옆자리 동료에게 한 판 제안 | 단톡방 링크를 폰이나 PC로 연다. 게임이라는 설명을 못 들었을 수 있다 | 한 판 중에도 뒤에서 팀장이 지나간다. 위장 신뢰가 최우선 |
| 목표 | 최소 조작으로 번호를 보내고 바로 시작 | 설명 없이 3탭 안에 첫 발을 쏜다 | 0.1초 안에 업무 화면으로 바뀌고, 돌아올 때 게임이 불쑥 뜨지 않는다 |
| 불안 | 상대가 안 오면 혼자 기다림 | 이게 뭔지 모르는 채 업무 링크로 오해 | Tab을 두 번 눌렀더니 게임이 튀어나옴 / 메모 글이 옆에서 읽힘 |
| UX 대응 | 배치하면서 기다림, 공유 패널 번호 크게 | 입장 대화상자의 "2인 좌표 게임 초대" 한 줄 + 규칙 보기 | 한 방향 숨기기, 복귀는 시트 탭 클릭, 웃음 문구는 3~7초만 노출 |

공통 환경: PC 마우스 우선(≥1024px), 모바일은 "링크를 폰으로 열어도 막히지 않는 수준". 키보드: 한글 입력 상태가 기본.

### 2-2. 상태 전이표 (화면 한 벌 = 시트 셸 하나, 바뀌는 건 셀·창 머리·상태줄·시트 탭)

|---|---|---|---|---|
| **H 홈** | 접속 | 시트 셸 없음(문서 앱 시작 화면) | 양식 선택, 닉네임, 경보 체크, 만들기, 번호 열기, 연습 | 만들기 → W / 열기 → W 또는 P / 없는 번호 → E3 |

### 4-7. B-Q 검산 요청 (오른쪽 창 10~13행 교체)

```
 ⑤ 오른쪽 창
        A      B      C      D    E    F    G      H
   9
  10   [ 팀장님 이번 주 아아 결제 합계 ──────────────────── ]        00:07      ← 라벨(≤24자, 병합 A~G) + 남은 시간(H)
  11   건명    1건    2건    3건                      (단위: 만원)  ← 머리글(≤4자) + 단위(G~H 병합)
  12   금액    47     38     21
  13   합계   [입력:Enter로 확정 ]                                              ← 오답이면 #VALUE! 3초 후 재입력 가능

```
- 값 칸·입력 칸: 숫자 키패드 의도(`inputMode=numeric`). 쉼표·전각 숫자·"원"은 허용(`quiz.ts`).
- **확정은 Enter만.** Tab을 누르면 숨기기(엑셀 습관 주의). 입력 칸 흐린 안내 글자 "Enter로 확정".
- 오답: 입력 칸이 `#VALUE!`로 바뀌고 3초 동안 입력 불가(회색). 오른쪽 칸(H13)에 한 줄 메모(공통 묶음 3개 중 랜덤, ≤40자). 3초 뒤 입력 칸이 비워지고 다시 입력 가능. **오답은 상대에게 보이지 않는다.**

- **검산 중에는 발사·힌트·의견 남기기가 모두 비활성**(버튼 흐림, 이유는 상태줄이 설명). 발사 시계는 멈춰 있으므로 상태줄 시간은 검산 마감만 보인다.

- 항목 표(10~13행)는 검산이 끝나는 순간 원래 내용으로 복귀.

### 4-8. B-H 힌트 사용 ([Σ] → 범위 고르기)

```
 ③ 도구줄: … Σ(2) … ← 클릭하면 모드 시작. 배지 숫자 = 지금 쓸 수 있는 힌트 수(받은 것 − 쓴 것)
 ④ [ E1:E8   ▾] │ ✕ ✓ fx │ =COUNTIF(E1:E8,">0")    ← 오른쪽 창에서 E열 머리글을 클릭한 상태
 ⑤ 오른쪽 창  열 머리글/행 번호/칸이 "선택 가능" 상태(커서 변경). 선택한 범위에 점선 테두리
      A  B  C  D [E] F  G  H  I
 ⑦ 상태줄: 검토할 열·행·셀을 선택하세요.   (✕ 또는 Σ를 다시 눌러 취소)
```
- 범위 선택: **열 머리글 = 열 전체**(`E1:E8`), **행 번호 = 행 전체**(`A3:H3`), **칸 = 그 칸 중심 3×3**(`B3:D5`, 가장자리는 판 안쪽으로 밀어 항상 3×3, 예: A1 → `A1:C3`) [방향서 §2-R]. 
- ✓ 또는 Enter로 확정 → "계산 중..." → 결과가 자리(U12)에 값으로 남고 점선이 사라짐. 배지 숫자 −1. **턴은 소모하지 않고 시계도 멈추지 않는다.**
- 결과 표시: 열 → `E9`에 `2`, 행 → `I3`에 `1`, 3×3 → "검토 의견" 표에 `B3:D5 │ 2 │ 14:30`. 수식 입력줄에는 확정 후 비운다.
- **취소 = ✕ 또는 [Σ] 재클릭.** (ESC는 숨기기라서 취소 키가 아니다. 숨기면 모드가 취소된다 — U4)
- 비활성 조건: 힌트 0개, 검산 중, 경보 중, 숨김 중. 비활성일 때 [Σ]에 마우스를 올려도 `title`은 쓰지 않고 상태줄에 이유를 1줄(예: "사용할 수 있는 검토 의견이 없습니다.").
- 상대 화면: 왼쪽 창 "변경 내역"에 한 줄 추가(값 없음), 상태줄은 건드리지 않는다.

### 4-9. B-A 결재 경보

```
 ④ [ B7 ▾ ] │ ✕ ✓ fx │ …
                  ┌─────────────────────────────────────────┐
                  │ 결재 요청 1건이 도착했습니다.      [Tab] │   ← 판 바로 위 가운데 고정, 두 사람 같은 위치·크기
                  └─────────────────────────────────────────┘
```

- 경보 직전부터 이미 숨어 있으면 0ms 통과(토스트는 게임 레이어에만 있으므로 숨어 있으면 보이지 않는다).
- **복귀 시 상태줄 5초**: 통과 `결재 요청이 처리되었습니다.` / 실패 `이번 회차 편집이 제한됩니다.`
- 검산과 겹치지 않는다(서버가 출제 조건에서 보장).
- 힌트 고르기·팝오버가 열려 있어도 토스트는 그 위에 뜨며(z-order 최상), 그 모드들은 U4에 따라 숨기는 순간 취소된다.

## 5. 와이어프레임 — 모바일 (<1024px, 창 하나)

공통: 메뉴줄·도구줄 생략. 상단바(파일명 + [⋯]) + 이름 상자·수식 입력줄 1행. [⋯] 메뉴에 `의견 남기기`, `검토 의견(Σ n)`, `인수인계서`, `문서 닫기`. 탭 높이·버튼 44px 이상. 판 칸은 정사각형(360px 폭 기준 약 40px), 가로 스크롤 없음.

```
 ┌ 360px ───────────────────────────────┐
 │ ▦ 월마감_최종_진짜최종_v7        [⋯]   │ 상단바
 │ [ B7 ▾] ✕ ✓ │ fx 0                    │ 이름 상자 + 수식 입력줄
 │     A  B  C  D  E  F  G  H            │ 열 머리글
 │ 1                                      │
 │ 2    ■  ■                             │  ← 상대 시트(내 차례에 자동 전환)
 │ ⋮                                      │
 │ 8                                      │
 │ 9  E9=2                                │
 ├────────────────────────────────────────┤
 │ B7 건은 검토 결과 해당 사항 없음으로    │ 메모 줄(13px, 최대 2줄, 같은 3~7초 규칙)
 │ 확인되었습니다.                         │
 │ [        B7 반영        ]   (44px)    │ 확정 버튼: 선택된 칸이 있을 때만 활성, 라벨에 좌표 표시
 │ [내 시트] [상대 시트]  │  [손익]        │ 시트 탭 (구분선 오른쪽 = 숨기기 탭)
 │ 편집 가능 · 00:14 · B7 선택됨          │ 상태줄
 └────────────────────────────────────────┘
```
- **선택 → 확정**: 칸 탭 = 선택, 같은 칸 다시 탭 또는 [B7 반영] 버튼 [방향서 §2-I]. 확정 버튼은 한 개뿐이다.
- **자동 시트 전환**: 내 차례가 시작되면 `[상대 시트]`로만 자동 전환. 상대의 발사 결과는 메모 줄에 "상대 검토: C4 해당 없음" (등급 2).
- **검산**: 창 맨 위(이름 상자 아래)에 4줄 표 고정. 숫자 키패드가 올라와도 가려지지 않게 `visualViewport` 위에 붙임. 확정 버튼 라벨이 `확인`으로 바뀜.
- **힌트**: [⋯] > `검토 의견`을 누르면 상대 시트가 선택 모드가 되고 열 머리글/행 번호/칸 탭 → 확정 버튼 `이 범위 검토`로 변경.
- **배치**: 끌어서 놓기 없음. 항목 줄 탭 → 칸 탭 → 방향 토글 버튼 `가로/세로`. **[자동 배치]를 가장 크게**(기본 강조), [배치 완료]는 그 아래.
- **숨기기**: `[손익]` 탭 탭, 경보 토스트 탭, 앱 전환·화면 잠금(자동). 물리 키보드가 있으면 Tab/ESC도 동작.
- **경보 토스트**: 화면 위쪽(상단바 아래), `[Tab]` 칩 대신 `[전환]` 칩 [UX결정: 터치 환경에 Tab 표기는 무의미]. 판정은 데스크톱과 동일(3초).
- **숨기기 시트 모바일 정의**: 4열만, 가로 스크롤, 선택만 되고 편집 불가, 차트 없음 [방향서 §2-H].
- **결과**: 단일 시트 탭으로 문서 표시, 작업 줄은 버튼 3개를 세로로 쌓음.
- 가로 모드도 모바일 배치(세로 우선).

## 6. 숨기기 시트 3종 (업종별 구조)

### 6-1. 공통 구조·동작

| 항목 | 규칙 |
|---|---|
| 크기 | 30행 × 10열 + 막대 차트 1개(데스크톱). 모바일은 4열 + 가로 스크롤 + 차트 없음 |
| 데이터 | 방·사용자별 seed로 **한 번만** 생성(sessionStorage 보존). 볼 때마다 바뀌지 않는다. 움직이는 칸은 "현재 시각"과 "마지막 저장"뿐 |
| 정합성 | 소계·합계·증감·비율은 정의된 열 규칙으로 실제 계산. 범용 수식 파서는 없음. 숫자 칸을 고치면 의존 칸이 즉시 재계산 |
| 웃음 문구 | **0개**(등급 0). 사람 이름 없음(인사·총무는 팀 코드). 급여·평가처럼 보이는 숫자 금지 |
| 이름 상자/수식 입력줄 | 선택 칸의 실제 주소/수식(`=SUM(D3:D9)`). 숨기는 순간 게임 값은 지운다 |
| 상태줄 | 숨김 중 "준비". 왼쪽 카운트·시간 없음, 오른쪽 `100%` |
| 창 | **분할 창 없음.** 단일 창 + 열/행 머리글. 시트 탭은 그대로(활성은 숨기기탭) |
| 탭 제목·상단바 | 그대로 둔다(바꾸면 그게 티) |

### 6-2. 키 동작 (숨기기 시트 안)

| 입력 | 동작 |
|---|---|
| 방향키 | 선택 이동 |
| Tab / Shift+Tab | 오른쪽 / 왼쪽 칸 (편집 중이면 확정 후 이동) — **게임으로 돌아가지 않는다** |
| Enter | 편집 확정 후 아래 칸 / 편집 시작이 아니면 아래 이동 |
| 숫자·글자 입력 | 선택 칸 편집 시작(기존 값 대체) |
| F2 / 더블클릭 | 편집 시작(기존 값 유지) |
| ESC | **편집 취소만.** 편집 중이 아니면 아무 동작 없음 |
| Ctrl/Cmd+S | 브라우저 저장 차단, 토스트 "저장됨" 1~2초 |
| 게임 탭 클릭 | **복귀**(직전 상태·선택·검산 입력값 복원) |
| 장식 탭/`+` 클릭 | 숨기기 시트 간 전환(게임으로 가지 않음) |

복귀 동선: 사용자는 **시선을 아래 시트 탭으로 이동 → 첫 번째 탭 클릭**. 이 동선이 1초 안에 가능해야 한다 → 게임 탭은 항상 **가장 왼쪽 첫 번째 탭**이고 호버 없이 클릭 가능한 크기(최소 28px 높이, 가로 ≥ 64px) [요청: UI].

### 6-3. 회계 `손익` — 월별 손익 요약
- 파일: `월마감_최종_진짜최종_v7` / 시트: `월결산`(게임), `손익`(숨기기), `비고`(장식)
- 열 10: A 구분 / B 계정과목 / C 전월 / D 당월 / E 증감(D−C) / F 증감률 / G 예산 / H 집행률(D/G) / I 담당 / J 비고
- 행 30: 구분 4개(매출·매출원가·판관비·영업외) × 계정과목 각 5~6개 + 구분별 **소계** 4행 + **합계** 1행 + 헤더 1행
- 계산 규칙: 소계 = 같은 구분 합, 합계 = 소계 합, 증감 = 당월−전월, 비율은 소수 1자리 %. 담당은 팀 코드(예: `FIN-1`), 비고는 대부분 빈칸
- 차트: 당월 구분별 막대 4개(강조 1 + 회색 3)
- 선택 초기 위치: `D3`(숫자 칸)

### 6-4. 영업·마케팅 `단계별` — 파이프라인 단계별 현황
- 파일: `파이프라인_v7` / 시트: `리드`(게임), `단계별`(숨기기), `목표`(장식)
- 열 10: A 고객사(A사~) / B 단계(리드·제안·견적·협상·계약) / C 견적가 / D 확률 / E 가중금액(C×D) / F 목표 / G 달성률(E/F) / H 최종 연락일 / I 담당팀(`영업1팀`) / J 비고
- 행 30: 단계별 5그룹 × 고객사 4~5개 + 단계별 **소계** 5행(합계 포함해 30행에 맞춤)
- 계산 규칙: 가중금액·달성률·소계·합계 자동. 최종 연락일은 고정 날짜(자동 갱신 없음)
- 차트: 단계별 가중금액 막대 5개
- 선택 초기 위치: `C3`

### 6-5. 인사·총무 `신청` — 부서별 연차 신청 현황

## 7. 인터랙션 노트

### 7-1. 숨기기·복귀 (방향서 §5-4 표 + UX 보충)
1. 게임 화면(입장 대화상자 포함 ESC만)에서 Tab/Shift+Tab/ESC → 같은 프레임에 숨기기 시트로 전환(서버 응답을 기다리지 않음).
2. 같은 프레임에 지우는 것: 고정 메모, 상태줄 문장(→ "준비"), 수식 입력줄/이름 상자(→ 숨기기 시트 값), 열린 드롭다운·팝오버·공유 패널·토스트·힌트 고르기 모드·검산 입력 포커스. **보존**: 선택 칸, 검산 입력값, 배치 초안, 결과 탭, 경보·재대결 요청의 유효성.
3. 창 이탈(blur / visibilitychange hidden / pagehide): 숨김. **돌아와도 숨긴 상태 유지**. 복귀는 게임 탭 클릭뿐.
4. 복귀 후 첫 5초 상태줄(U8): 상황별 1줄 — "편집 가능 · 00:14"(내 차례 진행 중) / "다른 사용자가 편집 중 · 00:14" / "검산이 마감되었습니다." / "결재 요청이 처리되었습니다." / "이번 회차 편집이 제한됩니다." / "편집 중단 시간이 한도에 도달했습니다." (숨김 120초 소진)
5. 숨기기 시트에서 Tab으로 게임이 튀어나오는 경로는 존재하지 않는다(키 이벤트는 시트가 먼저 소비).
6. 홈에는 숨기기가 없다. 연습에는 있다.

### 7-2. 키보드 동선과 접근성 (WCAG 2.1 AA 기준 점검)

- **포커스 가시성**: 전역 주황 링을 덮고(방향서 §8-2 #6) 셀 선택 2px 테두리, 버튼 1px 윤곽을 사용한다(2.4.7). 구체 색은 UI.
- **색 단독 의존 금지**: 해당 없음 `0` / 반려 `1` / 종결 짧은 이름 + 삼각형. 힌트 범위는 점선(1.4.1).
- **라이브 영역**: 상태줄과 메모는 `aria-live="polite"`, 경보 토스트는 `role="alert"`(보조기기 사용자는 경보를 즉시 듣는다). 메모 자동 닫힘 때문에 읽기 시간이 모자라는 사용자를 위해 닫힌 뒤에도 삼각형 호버/선택으로 다시 열 수 있다.
- **시간 제한(2.2.1)**: 20초 턴·10초 검산·3초 경보는 게임의 본질이라 필수 예외로 둔다. 숨기기 시계 정지·3턴 간격 등은 그대로. 홈에 고지.
- **MVP 제약 고지**: "시트 화면에서 Tab은 시트 전환 키입니다"를 홈 안내 상자에 적는다 [방향서 §5-4].
- 대비·글자 크기·터치 영역(모바일 44px)은 UI 스펙에서 AA(4.5:1) 점검.
- 모션: 셸 안 `transition: none`이라 `prefers-reduced-motion` 별도 처리 불필요.

### 7-3. 타이머·시계 표시 규칙
- 모든 시간은 **서버 시각 기준 카운트다운**을 해당 영역 안에서만 표시한다. 사용 위치: 상태줄(턴, 배치, 검산, 재대결 응답), 검산 표 H10. 깜빡임·색 변화 없음.
- 20초 턴: 5초 이하가 되어도 표시만 같다(움직임 금지). 만료는 즉시 상태줄 문구로만 알린다.

### 7-4. 로딩·서버 대기
- 최초 진입: 셸을 먼저 그리고 격자는 빈 상태, 상태줄 "문서를 여는 중…". 데이터가 오면 즉시 채운다(전체 화면 스피너 금지).
- 서버 대기: "계산 중..."은 **발사·검산 제출·힌트 확정** 서버 응답 대기에만 쓴다(방향서 §5-3).
- 재연결: "다시 연결 중…"(말줄임표는 한글 입력기 문자 `…` 하나).

## 12. 열린 질문

### UI디자이너에게
1. **인라인 팝오버(확인 창)·공유 패널·드롭다운**: 같은 컴포넌트 계열로 규격화해 주세요(네이티브 `dialog/alert/title` 금지). 취소 수단이 ESC가 아니라 ✕/버튼/바깥 클릭이라는 점 반영.
2. **종료 후 공개(빗금 + 흐린 짧은 이름)**와 반려/종결의 형태 구분(삼각형)이 흑백에서도 읽히는지, 해당 칸에 메모 삼각형과 빗금이 겹칠 때의 우선순위.
3. **`비고` 장식 시트**는 10행 안팎의 단순 메모형으로 가정했습니다(U7). 다른 안이 있으면 알려 주세요.
4. 게임 탭이 항상 맨 왼쪽·크게 클릭되는 탭 규격(복귀 클릭 1초 이내).
5. 결과 문서 3종의 결재란/서명란 레이아웃과 문서 작업 줄(버튼 3 + 피식 3 + 신고) 위계: [v8로 저장] > [내용 복사] > [다른 동료와 새 문서].
