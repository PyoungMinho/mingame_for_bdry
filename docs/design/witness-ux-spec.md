## 0. 한눈에

### 0-1. 전제 — 이 게임은 처음부터 1인용이다
- 질문 "혼자서 즐기는 모드도 넣은 거니?"에 대한 답: **전체가 혼자 즐기는 게임이다.** 별도의 '혼자 모드' 토글이 없다. 방 코드·초대·계정·서버·다인 투표가 없다. 한 사람이 폰 하나로 끝까지 한다.
- 「세자 독살 사건」(/gung, 술자리 4~6인)과 반대 자리다. 이쪽은 지하철·침대·점심시간에 혼자 25분.
- UX 반영: 타이틀에 칩 3개("혼자서" · "약 25분" · "가입 없음"), 설정 하단에 "이 기기에만 저장돼요"를 쓴다. 옆 사람이 구경하며 훈수 두는 건 막지 않는다(숨겨진 정보가 없고 화면이 한 장이라 자연스럽게 된다). 별도 기능은 만들지 않는다.

### 0-2. 핵심 결정 10줄
1. **고정 틀**: 상단 2행 HUD(시계+행동 12핍 / 한결 얼굴+신뢰 5칸+결정적 별 게이지)는 모든 인게임 화면에서 같은 자리다. 하단 탭바 3개(집 안 · 사람 · 수첩)는 엄지 영역에 둔다. 시스템 1-4의 상단 세그먼트를 하단으로 내렸다.
2. **유료 행동은 항상 두 번 탭한다.** 비용 칩(무료 / 행동 1 / NEW / 잠김)을 미리 보여 주고, 탭하면 비용 프롬프트(남은 행동 n → n-1)가 뜬다. 행동 2 이하는 시트로, 행동 1은 '마지막 행동' 전용 시트로 올린다.
3. **조사 화면은 점 지도 + 핫스팟 레일(칩 목록) 이중 구조**다. 지도를 끌어 헤매지 않아도, 레일만으로 모든 핫스팟에 닿는다. 정밀 조사에는 시계 아이콘과 비용을 누르기 전에 보인다.
4. **심문 = 증언 한 줄 카드 + ◀▶ + 하단 두 버튼**(추궁 / 증거 제시, 주 버튼은 오른쪽). 줄 상태는 점으로 표시한다(추궁함 · 깨짐 · NEW). 왼손 모드로 좌우를 뒤집을 수 있다.
5. **증거 고르기 시트**는 맨 위에 대상 줄을 고정해 보여 주고(줄 오선택 방지), 슬롯 A/B + 3열 카드 그리드로 간다. 한 장 → [이걸로!] 또는 [하나 더 겹치기]. 반쯤 맞음 뒤에는 방금 낸 카드를 슬롯에 남겨 둔다.
6. **판정 5종**(★돌파 · ◆돌파 · 반쯤 맞음 · 우회 · 오답)은 색만으로 구분하지 않는다. 모양+글자+모션+진동 4채널로 구분하고, 감점이 없는 두 가지(반쯤·우회)에는 "감점 없음" 칩을 반드시 붙인다. 신뢰 칸은 오답에서만 깨진다.
7. **돌파 결과 카드**(정정 진술 + 해금 목록 + 각 비용 칩 + 바로가기)를 연출 뒤에 띄운다. 토스트는 사라지지만 결과 카드는 사라지지 않아서, "뭐가 열렸는지 놓침"을 막는다.
8. **수첩은 어디서나 1탭**이다. 증거 · 인물 · 타임라인 · 의문 4탭이고, 타임라인은 엇갈림을 자동으로 표시하지 않는다(풀이를 대신하지 않는다). 의문 탭 아래에 "정리된 것"(깬 모순의 `explain`)을 쌓아 무료 힌트로 쓴다.
9. **튜토리얼은 행동으로 배운다**: 규칙 카드 3장 → 거실 조사(첫 점은 강제) → AI 브리핑 심문(추궁 → 제시). 한결 코치마크 15개는 평생 1회만 뜬다. 막힘 사다리는 추궁(무료) → 의문(무료) → 타임라인(무료) → 수첩 정리(행동 1)다.
10. **25분 템포**: 글자 속도 보통 36자/초 · 빠름 80자/초 · 즉시, 탭 2단계(완성 → 다음), 연출 합계 약 2분(목표 3분 이하), 정체 넛지, 플레이 시간은 화면이 보일 때만 센다. 매 상태 변화마다 자동 저장하고 새로고침에도 같은 자리로 돌아온다. 접근성은 WCAG 2.1 AA, 모션 줄이기, 360/375px 한 손 조작이 기준이다.

| 상황 | 지하철 출퇴근, 한 손, 소리 끔. 역전재판·크라임씬류를 좋아함 | 카톡 링크로 들어옴. 규칙 안 읽음. 3분 안에 재미가 없으면 나감 | 진상을 안다. S 등급과 숨은 엔딩 노림. 설명이 길면 짜증 | 저시력(글자 확대), 적녹 색약. 스크린 리더는 가끔 |

### 1-2. 사용 맥락 가정 (전부 기본값에 반영)
- **세로 한 손, 소리 꺼짐, 중간에 끊김**(전화·환승·알림). → 효과음 기본 꺼짐(어차피 P1), 진동 기본 켬, 자동 저장, 턴제라 실시간 압박 없음.
- 화면 폭 360~430px. 설계 기준 폭 **375px**, 최소 360px, 320px까지 가로 스크롤 없이 깨지지 않을 것. 데스크톱은 가운데 480px 열 하나만(별도 데스크톱 레이아웃 없음, 키보드 조작은 지원).
- 인터넷은 처음 로드 뒤에 필요 없다(공유만 예외). 모든 글·그림은 번들에 들어 있다.

### 1-3. 레퍼런스 — 가져올 것 / 버릴 것
| 레퍼런스 | 가져올 것 | 버릴 것 / 주의 |
|---|---|---|
| 역전재판 류 증언 심문 | 줄 단위 증언, 추궁과 제시의 이원 구조, 오답 게이지 | 고유 문구·캐릭터·UI 그대로 사용 금지(자체 컷인 3종만) |
| Return of the Obra Dinn | 틀려도 바로 판정하지 않고 묶음으로 확인하는 억제 방식 | 지목 3칸은 이 감각을 쓴다: 제출 전까지 판정 없음, 제출 후 수정 불가 |
| The Case of the Golden Idol | 증거 카드를 겹쳐 쓰는 감각, 정리된 사실을 노트에 누적 | 빈칸 채우기 퍼즐 UI는 모바일 한 손에 무거워서 채택 안 함 |
| 일반 비주얼노벨 | 탭 2단계 진행, 읽은 대사 빠른 넘김 | 자동 넘김(Auto) 제공 안 함 — 접근성(WCAG 2.2.1) 이유와 턴제 이유 |

### 2-2. 핵심 루프(한 사이클, 평균 2~3분)
```

### 2-4. 행동 0 · 신뢰 0 처리
```
행동이 0이 되는 순간이 "증언을 연 행동"이면
  → 그 세트는 끝까지 한다(추궁·제시 가능). HUD에 "마지막 증언 · 나가면 사이렌" 태그.
  → 세트에서 나오는 순간 W12 사이렌(3초, 깜빡임 없음)
행동이 0이 되는 순간이 "장소·정밀 조사"이면
  → 그 장소의 핫스팟은 끝까지 본다. 나오는 순간 W12.
W12 이후: 이미 연 증언·장소 재진입 막힘(카드에 "사이렌 뒤라 못 들어간다" 표시)
          수첩 열람 · 최종 지목은 열려 있다.
  ├─ ★ ≥ 3: "시간이 다 됐다. 지금 가진 걸로 지목한다." → W50(경고·확인 생략)
  └─ ★ < 3: 「시간 초과」 엔딩

신뢰가 0이 되는 순간: 오답 연출(약 2초) 끝까지 보여 준 뒤 W65 「수사 배제」
```

타이틀 [이어하기] ─▶ screen.name 복원

## 4. 공통 요소 — HUD · 비용 · 피드백

### 4-1. HUD (인게임 상단 고정)

**풀 모드(허브·수첩)**
```
┌──────────────────────────────────────
│ [Clock] 23:40  ●●●● ●●●○ ○○○○   [7]  [⋯]
│ 강력팀 도착까지 70분
│ (한결 얼굴) ■■■■□ 신뢰 4        [Star]★★☆ 2/3
```
**컴팩트 모드(조사·심문·대질·시트 안)**
```
┌──────────────────────────────────────
│ [<]  (한결)■■■■□   [Clock]7  [Star]2/3   [NotebookPen]
```

| 요소 | 규칙 |
|---|---|
| 시계 | 23:00 시작, 행동 1 = 10분. 행동 0 = 01:00. 숫자는 `aria-label="23시 40분, 강력팀 도착까지 70분"`. |
| 행동 핍 | 12개를 4개씩 3묶음. 남음 = 채운 원, 씀 = 빈 원(+외곽선). 오른쪽 숫자 칩 `7`을 항상 함께 쓴다(색·모양 외 숫자 채널). |
| 예고 핍 | 비용 프롬프트가 떠 있는 동안 곧 쓸 핍이 외곽선으로 깜빡인다(느린 호흡, 3회 후 정지). |
| 신뢰 | 5칸. 채운 네모/빈 네모. 왼쪽에 한결 얼굴(5단계, 4-5). 칸이 깨지는 연출은 오답에서만. |
| ★ 게이지 | `Star` 3개. 비어 있음 = 외곽선, 참 = 금색 채움. 3/3이 되면 "고발 준비 완료"로 바뀐다. **총 개수(5~7)는 보여 주지 않는다**(시스템 5장, 스포일러 방지). |
| ◆ | 일반 모순은 HUD에 세지 않는다(지목 조건이 아니다). 결과 카드에서만 `Diamond` 아이콘으로 표시한다. |
| `[⋯]` | 설정 · 도움말 · 제목으로. 위험 항목(기록 삭제)은 설정 시트 안쪽에 둔다. |
| 접근성 | HUD 값 변화는 `role="status"` 폴라이트 라이브 영역으로 읽는다("행동 6 남음, 23시 50분"). 연속 변화는 600ms 디바운스로 합쳐 읽는다. |

### 4-2. 비용 칩 (모든 진입 카드·핫스팟에 사전 표기)

| 칩 | 뜻 | 모양 | 텍스트 |
|---|---|---|---|
| 무료 | 비용 0(튜토리얼·재방문·★ 해금) | 초록 외곽선 + `Check` 없음 | "무료" |
| 행동 1 | 첫 진입/첫 열람 | 앰버 채움 + `Clock` | "행동 1" |
| +1 | 정밀 조사 | 핫스팟 점에 `Clock` 겹침 + 레일 칩에 `+1` | "행동 +1" |
| 다녀옴 | 이미 들어간 곳(재방문 무료) | `Check` + 흐린 처리 | "다녀옴" |
| NEW | 해금으로 생긴 새 핫스팟·증언 | 앰버 점 + 텍스트 | "NEW · 무료" 또는 "NEW · 행동 1" |
| 잠김 | 해금 전 | `Lock` | "잠김" + 스포일러 없는 문구 |
| 다 털었다 | 모든 모순 깸 | 도장 | "다 털었다" |
| 사이렌 뒤 | 행동 0 이후 재진입 불가 | `Lock` | "사이렌 뒤라 못 들어가요" |

- **잠김 문구는 무엇으로 풀리는지 말하지 않는다**("문이 안에서 잠겨 있다. 손님 짐이 있다." 같은 `lockedLabel`만 쓴다).
- ◆ 일반 돌파로 열린 것은 그 종류의 기본 비용 칩을 그대로 단다("행동 1"). ★ 돌파로 열린 것만 "무료"가 붙는다. 이 차이가 결과 카드(W11)에서 보여야 한다.

### 4-3. 비용 프롬프트 (유료 행동 직전, 3단계)

| 남은 행동 | 형태 | 문구 |
|---|---|---|
| **3 이상** | 하단 **인라인 프롬프트 띠**(탭바 바로 위, 조사 중에는 대사 박스 안) | `{대상} · 처음 들어간다 · 행동 1 (7 → 6)` `[들어간다]` `[닫기]` |
| **2 이하** | **확인 시트** | 제목 "남은 행동 2 → 1" / 본문 "정말 쓸까요?" / `[쓴다]` `[돌아간다]` |
| **1 (마지막 행동)** | **전용 시트**(시스템 1-4 v2) | 아래 상세 |

**정밀 조사 프롬프트(남은 행동 3 이상)**: "⏱ 행동 1이 더 든다. (남은 행동 7 → 6)" `[조사한다]` `[나중에]`(시스템 대본 6장 문구 그대로).

**마지막 행동 시트 상세** (대본 6장 문구 그대로 + 보조 한 줄)
```
┌──────────────────────────────────────
│ [Siren] 마지막 행동
│
│ 이게 마지막 행동이다.
│ 끝나면 사이렌 — 이미 연 증언에도 다시 못 들어간다.
│ 그래도 할까요?
│
│ (장소·정밀 조사일 때만 한 줄 추가)
│ 여기서 얻는 증거는 증언에 내밀 수 없다.
│ (공통 보조 한 줄, 작은 글씨)
│ 수첩과 최종 지목은 사이렌 뒤에도 열려 있다.
│
│ [수첩 먼저 보기]                 (텍스트 링크, 40자 이하)
│ [   돌아간다   ]  <- 기본 포커스, 주 버튼
│ [ 그래도 한다 ]   <- 보조(외곽선)
└──────────────────────────────────────
```
- 이유: 블라인드 2명 모두 이 규칙 때문에 마지막 정밀 조사를 포기했다. 취소 쪽을 시각적 기본값으로 두어 오확정을 줄이고, `[수첩 먼저 보기]`로 결정 전에 정리할 길을 둔다.
- 증언 세트가 마지막 행동일 때는 "여기서 얻는 증거는…" 줄을 뺀다(그 증언은 끝까지 할 수 있으므로).

| 사건 | 시각 | 촉각(진동, 지원 기기만) | 소리(P1) | 텍스트·보조기술 |

| 신뢰 0 | 오답 연출을 끝까지 보여 준 뒤 W65로 전환 | [80,40,80] | | |
| ★ 증가 | 별 채움 + 짧은 광택 1회 | [30,40,60] | 높은 톤 | 라이브 "결정적 모순 2" |

### 5-1. W01 타이틀
```
┌──────────────────────────────────────
│                                [⚙]    <- 설정(44px)
│  (키아트: 비 오는 창, 거실, 파란 LED 링)
│
│  스마트홈 살인사건
│  목격자는 AI 스피커
│
│  [User]혼자서   [Clock]약 25분   [ShieldOff]가입 없음
│
│  ┌ 이어하기 ─────────────────────────  <- 저장이 있을 때만, 주 버튼(금색)
│  │ 23:40 · 행동 7 남음 · 증거 9개 · 신뢰 ■■■□□
│  │ 어제 22:14 저장
│  └────────────────────────────────────
│  [        새 수사        ]              <- 저장 있으면 보조(외곽선), 없으면 주 버튼
│  [ 엔딩 도감 ]      [ 설정 ]
│
│  소리 꺼짐 · 진동 켬  (탭하면 바뀐다)
└──────────────────────────────────────
```
- 새 수사 + 저장 있음 → **W71 확인**: "지금 수사 기록이 지워져요. (엔딩 도감·업적은 그대로예요)" `[새로 시작]` `[취소]`(취소가 기본 포커스).

│ └─────────────┘  └──────────────┘
│ [증거 11]  [인물 6]          정렬 [최근 ▾]  종류 [전체 ▾]
│ ┌─────┐ ┌─────┐ ┌─────┐
│ │[Pkg]│ │[Cpu]│ │[Doc]│                  <- 3열 카드 타일(≈108px)
│ │트로피│ │22:20│ │초동 │
│ │     │ │기록 그대로│ │메모 │
│ └─────┘ └─────┘ └─────┘
│ (스크롤)
│ ─────────────────────────────────────
│ 선택: 순경의 초동 메모 — 22:39 발견…    <- 선택한 카드 요약 1줄(45자)
│ [ 하나 더 겹치기 ]        [  이걸로!  ]
└──────────────────────────────────────
```
**상태 2: 두 장 선택**
```
│ ┌슬롯 A───────┐  ┌슬롯 B───────┐
│ │ 증거 이름 [x]│  │ 증거 이름 [x]│        <- 슬롯 탭 = 그 카드만 해제
│ └─────────────┘  └──────────────┘
│ ...
│ [   닫기   ]              [  함께 제시  ]
```
- **카드 타일**: 종류 아이콘(item `Package` / log `Cpu` / doc `FileText` / photo `Camera` / memo `StickyNote`) + 이름(12자, 2줄) + 태그. 로그 태그는 `기록 그대로`(회색) / `위조`(붉은) / (확인된 기록은 태그 없음, 대본과 일치 — 12-1 R9) + 시각 칩 `22:20`. 새 증거는 `NEW` 점. 선택 = 금 테두리 + `Check` + 슬롯 글자(A/B).
- **인물 탭**: 용의자 4 · AI · 피해자 6장. 제시 가능(시스템 3-3). 지목 3칸에서는 비활성(W51).
- **정렬 기본 = 최근 획득 순**(방금 얻은 증거를 바로 쓰는 흐름이 많다). 선택지: 최근 / 시각 순 / 종류별. **관련도 자동 정렬·강조는 하지 않는다**(정답을 알려 준다).
- **미리보기**: 카드 탭 = 선택 + 하단에 요약 1줄. 상세 3줄은 길게 누르기(450ms, 진동 10ms) 또는 타일의 `[Info]`. 오제시 방지를 위해 "선택 → 확인 → 제시" 3단을 일부러 둔다.
- **교체 규칙**: 슬롯 A·B가 다 차 있을 때 새 카드를 탭하면 B가 교체된다. A를 바꾸려면 A 슬롯을 먼저 해제한다.
- **직전 선택 유지**: 반쯤 맞음(HALF) 직후에 이 줄에서 시트를 다시 열면 방금 낸 카드가 슬롯에 남아 있고 슬롯 B가 한 번 깜빡인다. 이 줄을 깼거나 세트를 나가면 초기화(UI 상태, 저장 안 함).
- **하단 안내(처음 3번 열 때)**: "두 장을 겹쳐 낼 수도 있다. 하나 고르면 [하나 더 겹치기]가 켜져요." 이후는 `[Info]` 뒤로 접는다.
- **더블탭 방지**: 제시 버튼은 첫 탭 후 즉시 비활성(판정 중 중복 제출 불가).
- **닫기**: 핸들 아래로 끌기(목록이 맨 위일 때만) · ✕ · 스크림 탭 · 뒤로가기 · Esc. 포커스 트랩 + 닫으면 [증거 제시] 버튼으로 포커스 복귀.

│ └─────────────┘   └─────────────┘

- 대질은 ★ 해금(무료)이라 비용 칩 "무료"만 표시하고 프롬프트를 거치지 않는다.

### 5-8. W40 수첩
수첩은 허브의 세 번째 탭(하단 탭바 유지)이자, 조사·심문 헤더의 아이콘으로 여는 풀스크린 시트(하단 탭바 숨김, ✕로 닫기)다. **같은 컴포넌트**를 두 곳에 마운트한다.

#### (a) 증거 탭
```
├──────────────────────────────────────
│ [증거 11/18] [인물] [타임라인] [의문 3]
│ ┌ 수첩 정리 — 막혔을 때 ───────────────┐
│ │ 행동 1 · 남은 2회       [ 정리하기 ] │
│ └──────────────────────────────────────┘
│ 정렬 [최근 ▾]   종류 [전체 ▾]
│ ┌─────┐ ┌─────┐ ┌─────┐
│ │[Doc]│ │[Pkg]│ │[Cpu]│
│ │초동 │ │트로피│ │22:20│
│ │메모 │ │     │ │기록 그대로│ NEW
│ └─────┘ └─────┘ └─────┘
│ ┌ ? ──┐ ┌ ? ──┐ ┌ ? ──┐         <- 실루엣(점선), 이름·내용 없음
│ └─────┘ └─────┘ └─────┘
```
- 18칸 격자, 얻은 것만 보이고 나머지는 점선 실루엣 "?"(시스템 3-7). 총 개수 `11/18`은 보인다.
- 갱신된 카드는 `갱신` 리본. 상세에서 `이전 기록 보기`로 원본(raw)을 읽을 수 있다(원본은 제시·지목에서 더는 쓸 수 없다).
- 빈 상태(튜토리얼 직후 아님, 거실 전): "아직 수첩이 비었다. 현장부터 보자."

#### W41 증거 상세 (시트)
```
│ [Cpu] 22:20 음성 명령          [기록 그대로]
│ 시각 22:20 · 출처 거실 · 또박이
│ 22:20:01 주인 음성 '또박아, 불 꺼. 오늘은 여기까지.'
│ 또박이가 주인 목소리로 판정, 거실 조명을 껐다.
│ 기록 그대로. 진위는 확인되지 않았다.

```
- `쓴 곳`은 쓰고 난 뒤에만 보이고, 어느 줄인지·무엇이 정답이었는지는 쓰지 않는다. 앞으로 쓸 곳은 절대 보여 주지 않는다.

#### (b) 인물 탭
```
│ [증거] [인물 6] [타임라인] [의문 3]
│ ┌─────┐ 선우강 (49) · 공동창업자·CTO
│ │초상 │ 또박이 설계자. 회색 후드티…
│ └─────┘ 매각에 반대해 왔다는 소문이 있다.
│         (비밀이 풀리면 한 줄 추가)

```
- 카드를 탭하면 상세. 심문 중 제시는 W31의 인물 탭을 쓴다(수첩 탭에서는 읽기 전용).

#### (c) 타임라인 탭 — 목록형(P0), 축 그래픽은 P1
```
│ [증거] [인물] [타임라인] [의문 3]
│        기록 (실선)          주장 (점선)
│ 21:30                       ┆ 하늘 · "9시 반에 아빠랑 싸웠어요."
│ 21:38 ┃ 삭제 명령 기록 [기록 그대로]
│ 22:20 ┃ 22:20 음성 명령 [기록 그대로]
│ ...
```
- 21:00~23:00 시간순. 왼쪽 열 = 시각이 있는 증거(기록, 실선), 오른쪽 열 = `claimTime`이 있는 증언(주장, 점선). **엇갈림은 자동으로 표시하지 않는다.** 같은 시각 근처에 두 열이 나란히 서는 것이 전부다(시스템 3-7 "눈에 보인다").
- 시각 눈금은 항목이 있는 시각만 행으로 만든다(없는 시각은 접음). `[전체 눈금]`은 P1.
- 항목을 탭하면 해당 카드/줄 상세. 화자는 이름 텍스트 + 색 띠.
- 빈 상태: "시각이 적힌 증거와 증언이 쌓이면 여기에 줄이 선다."

#### (d) 의문 탭
```
│ [증거] [인물] [타임라인] [의문 3]
│ 풀리지 않은 의문
│  ? 9시 반, 회장과 큰 소리로 다툰 사람은?
│  ? 21:41부터 15분, 왜 기록이 비었나?
│ 풀린 의문
│  ~~? 10시 3분 인사에…~~  ✓ (금 선)
│ ── 정리된 것 ────────────────────────
│  [Diamond] 회장은 22:39 거실 바닥에서 발견됐다. 움직이지 않았을 뿐.
│  [Star] ...
│ ── 수첩 정리 메모 ─────────────────
│  정리 1: "…" [그 증언으로]
```
- **의문**(시스템 3-7)은 추궁으로 생기고, 관련 돌파가 일어나면 줄이 그어진다. 무료 힌트다.
- **정리된 것**(신규): 깬 모순의 `explain`(≤45자)을 시간순으로 쌓는다. ★은 `Star`, ◆는 `Diamond` 아이콘과 텍스트("결정적"/"해소"). 개수 총합은 보이지 않는다. 플레이어가 지금까지 증명한 것을 한눈에 되짚는 곳이라 힌트 사용을 줄인다. `explain`은 "그 모순이 증명한 것"만 말해야 한다(12-1 R7).
- **수첩 정리 메모**: 사용한 힌트(≤2) 본문을 다시 읽을 수 있게 보관(재열람 무료).

#### W42 수첩 정리 (힌트)
```
┌──────────────────────────────────────
│ [NotebookPen] 수첩 정리
│ 행동 1 · 남은 2회 → 1회
│ ──────────────────────────────────
│ (나) 〈인물〉의 「〈세트 제목〉」.
│      '〈주제〉' 얘기가 걸린다. 가진 걸로 충분하다.   <- 시스템 3-8 ① 형식 예시
│ ──────────────────────────────────
│ [ 그 증언으로 ]         [ 닫기 ]
└──────────────────────────────────────
```
- 진입은 4-3 비용 프롬프트(남은 행동 ≥3 인라인, ≤2 시트, =1 마지막 행동 시트). 쓰기 전에 어떤 종류의 말이 나오는지 한 줄 예고: "어디를, 어떤 주제를 짚어 줘요. 정답은 말하지 않아요."
- 본문은 시스템 3-8 ①②③ 형식을 그대로 쓴다(증거 이름·줄 번호·정답 금지). 결과 시트 타이핑 후 **수첩 정리 메모에 자동 보관**한다.
- `[그 증언으로]`/`[그 장소로]`는 대상 카드로 이동해 2회 깜빡이는 강조만 한다. 비용이 있는 대상이면 4-3 프롬프트를 거치고 **자동으로 행동을 쓰지 않는다**.
- ③ 경로 끝 문구("이제 지목해도 된다. 수단·기회·동기, 하나씩.")일 때 버튼은 `[최종 지목으로]`로 바뀐다.
- 남은 횟수 0이면 버튼 비활성: "수첩 정리는 다 썼다".

#### W51 수단 · 기회 · 동기

## 6. 인터랙션 노트

### 6-1. 판정 연출 타임라인 (보통 / 연출 간소화 켬은 ×0.5, 모션 줄이기는 6-5)

공통 전반: `t=0` [이걸로!] 탭 → 시트 닫힘(180ms) → 컷인 「증거 나간다!」(450ms) → 카드가 대상 줄로 날아가 박힘(250ms) → **판정 확정** → 아래 분기.

| 판정 | 시각 | 글자 | 촉각 | 상태 변화 | 다음 |
|---|---|---|---|---|---|
| **BREAK ★** | 「앞뒤가 안 맞아!」 컷인 600ms · 흔들림 6px×3(240ms) · 흰 플래시 100ms(**1회**) · 줄 붉은 취소선 · 초상 shock · 금색 도장 「결정적」 쾅(400ms) · 신뢰 칸 금빛 채움 | 반응 대사 ≤4줄(탭 진행) → 정정 진술 | [30,40,60] | 신뢰 +1(최대 5), ★ +1, 해금 적용 | W11 결과 카드(★ 라벨) |
| **BREAK ◆** | 컷인 400ms(플래시 없음) · 줄 취소선 · 작은 도장 「모순 해소」 · 초상 shock | 반응 대사 ≤4줄 | [30,40] | 해금 적용(회복 없음) | W11(◆ 라벨) |
| **HALF 반쯤 맞음** | 줄이 2회 비틀림(skewX ±2°, 300ms) · 초상 sweat · 도장 없음 · 카드가 슬롯으로 복귀 | `half` 대사(카드별 있으면 그것, 없으면 "흔들린다… 그런데 딱 맞진 않는다.") + **칩 「감점 없음」** | [20] | 변화 없음 | 심문 복귀, 직전 선택 유지 |
| **REDIRECT 우회** | 카드가 손으로 미끄러져 복귀(`Undo2`, 250ms) · 흔들림 없음 · 초상 normal | `redirect.say`(≤3줄) + **칩 「감점 없음」** | 없음 | 변화 없음 | 심문 복귀 |
| **WRONG 오답** | 카드가 튕겨 나옴 · 붉은 비네트 150ms(**플래시 아님**) · 신뢰 칸 금 가며 떨어짐 280ms · 한결 얼굴 한 단계 아래 | 인물 오답 리액션 1~2줄(3종 순환, 직전과 다르게) + 독백 "…헛다리였다." | [50,40,50] | 신뢰 −1, wrong +1 | 심문 복귀(0이면 W65) |
| **이미 깬 줄** | 연출 없음 | 토스트 "이미 깨진 얘기다" | 없음 | 변화 없음 | 시트에서 이 줄에 [증거 제시] 자체가 비활성이라 도달 어려움 |

- **구분 4채널**: ① 컷인·도장의 **글자**, ② **아이콘 모양**(`Star` · `Diamond` · `Waves`(흔들림) · `Undo2` · `X`), ③ **모션**(쾅 / 비틀림 / 복귀 / 튕김), ④ **진동 패턴**. 색은 보조일 뿐이다.
- **「감점 없음」 칩**: HALF·REDIRECT 때 줄 카드 오른쪽 위에 1.6초 떠 있다. 이 칩이 "신뢰 칸이 안 깨졌는데 뭐가 일어난 거지?"를 막는다. 신뢰 칸 옆에도 `±0`을 흐리게 1회 비춘다.
- **첫 발생 코치마크**(15개 중): HALF 처음 → "반쯤 맞음은 감점이 없어요. 방향은 맞아요. 두 장을 겹치거나, 먼저 풀어야 할 게 있을 수도 있어요." / REDIRECT 처음 → "감점 없음. 이 줄이 아닐 뿐이에요." (특정 해법을 말하지 않는다.)
- **오답 순환**: 인물별 3종을 `index = wrongCountBySuspect % 3`로 순환(랜덤 아님 — 테스트 가능성과 직전 반복 방지).
- **오답 0칸 도달**: 위 연출 끝까지 → 「수사 배제」.

| 핫스팟 | 탭 | 조사(대사·획득) | 레일 칩, Tab/Enter |
| 증거 타일 | 탭 / 길게(450ms) | 선택 / 상세 미리보기 | 타일의 `[Info]` |
| 시트 | 아래로 끌기 | 닫기(목록 맨 위일 때만) | ✕, 스크림, 뒤로가기, Esc |
| 규칙 카드 | 좌우 스와이프 | 이전/다음 | 버튼 |
| 모든 화면 | 핀치 줌 없음 | 브라우저 확대는 허용(최대 5배) | 설정 글자 크기 |
- 가장자리 20px 스와이프는 인식하지 않는다(iOS 뒤로 제스처 충돌 방지). `touch-action: manipulation`으로 더블탭 확대를 막되 핀치는 둔다. 쉘에 `overscroll-behavior: contain`으로 당겨서 새로고침을 막는다.
- 길게 누르기와 드래그는 **필수 경로에 쓰지 않는다**(WCAG 2.5.1).

### 6-3. 트랜지션
| 전환 | 모션 | 시간 |
|---|---|---|
| 허브 탭 간 | 크로스페이드 | 120ms |
| 허브 → 조사/심문 | 문 여는 페이드 스루(검정 경유) | 220ms |
| 시트 열림/닫힘 | 아래에서 슬라이드 + 스크림 | 220 / 180ms |
| 결과 카드 | 스케일 0.96 → 1 + 페이드 | 200ms |
| HUD 값 변화 | 숫자 롤링 / 핍 채움 | 200~280ms |
| 첫 진입 장면 | 비 오는 창 파티클 약하게(최대 20개, 정지 가능) | 상시 → 모션 줄이기에서 정지 |
- **상시 루프 애니메이션은 모두 3회 후 정지**한다(WCAG 2.2.2). 화면 복귀 시 다시 3회.
- 번쩍임은 **한 번의 100ms 플래시**만(WCAG 2.3.1, 초당 3회 초과 금지).

### 6-4. 대사 타이핑 상수 (튜닝 한 곳에 모은다: `wt-ux-constants`)
| 상수 | 값 |
|---|---|
| 보통 / 빠름 / 즉시 | 36 / 80 / 무한 자·초 (45자 줄 = 약 1.25초 / 0.56초 / 0) |
| 문장부호 멈춤 | `…` 160ms · `.?!` 90ms · `,` 40ms (빠름은 절반) |
| 줄당 상한 | 1,400ms(길어도 이 안에 끝남) |
| 읽은 대사(2회차 이상, 설정 켬) | 즉시 표시 |
| 컷인(제시/돌파★/돌파◆/추궁) | 450 / 600 / 400 / 350ms, 연출 간소화 ×0.5 |
| 토스트 | 1.2초(행동·획득) / 4초(사이렌 접근) — **토스트가 유일한 정보원이면 안 된다**(수첩·허브 배지에도 남는다) |
| 길게 누르기 | 450ms |
| 정체 넛지 | 허브에서 150초 무입력, 120초 안에 오답 2회 |

### 6-5. 모션 줄이기(접근성)
- 기본값은 OS의 `prefers-reduced-motion`을 따르고 설정에서 덮어쓸 수 있다.
- 켜면: 흔들림·비틀림·플래시·파티클·번짐 제거 → 도장은 페이드 인, 컷인은 정지 문구 0.6초, 핍/칸 변화는 즉시(색+모양 변경만), 타이핑은 즉시 표시, 장면 이동은 점프.
- 판정 4채널 중 ③ 모션이 빠져도 ①②④가 남아 구분이 유지돼야 한다(진동이 꺼졌으면 ①②가 남는다).

## 8. 25분 템포 설계

### 8-1. 시간 예산 (시스템 2-4의 약 27분에 UX 레버를 얹은 목표)

| 구간 | 시스템 예산 | UX 목표 | 레버 |
|---|---|---|---|
| 타이틀~사건 소개~규칙 | 2분 | 1분 40초 | 컷 8개 ≤ 80초, [≫ 빠르게] |
| 튜토리얼(거실+브리핑) | 3분 | 3분 | 첫 점 강제, 코치마크 한 탭 |
| 조사 4~5곳 | 5분 | 4분 | 레일(탐색 시간 제거), 기기 로그 [담기] 1탭 |
| 심문·대질 7~8세트 | 13분 | 12분 | 글자 속도, 한 탭 2단계, 추궁 즉시 재생, 결과 카드 바로 가기 |
| 수첩·타임라인 고민 | 2분 | 2분 | 정리된 것, 의문, 정렬 기본 최근순 |
| 최종 지목~엔딩 | 2분 | 2분 20초 | 판정 연출 칸 단위 건너뛰기, 2회차 [전부 건너뛰기] |
| **합** | **약 27분** | **약 25분** | |

### 8-2. 병목은 읽기다
- 평균 노출 약 10,000자 ÷ 짧은 대사 읽기 약 600자/분 ≈ **17분**. 여기에 연출 약 2분 + 생각·탐색 약 6~8분이 더해져 25~27분이 된다. 작가 상한(15,000자)에 가까워지면 90퍼센타일 35분을 넘길 위험이 크다.
- 그래서 대사 한 줄 45자 상한은 UX 제약이기도 하다: 375px에서 17px 글자는 한 줄에 약 18자 → 45자 = 3줄. 대사 박스 최소 높이는 **3줄 + 화자 줄**(약 130px)로 고정해 줄 수가 변해도 레이아웃이 튀지 않게 한다.
- **블라인드 테스트에 "노출 글자 수"를 계측**하고, 플레이 시간 중앙값 22~28분 · 90퍼센타일 35분 이하를 확인한다(시스템 2-4 게이트).

### 8-3. 연출 시간 예산 (목표 합계 3분 이하, 약 2분 10초 예상)
| 항목 | 횟수 | 1회 | 합 |
|---|---|---|---|
| ★ 돌파 | ~5 | 2.4초 | 12초 |
| ◆ 돌파 | ~6 | 1.3초 | 8초 |
| 반쯤/우회 | ~6 | 1초 | 6초 |
| 오답 | ~3 | 2초 | 6초 |
| 증거 획득 카드 | ~14 | 1.2초 | 17초 |
| 행동 소비(핍·시계) | ~12 | 0.8초 | 10초 |
| 시트·화면 전환 | ~100 | 0.2초 | 20초 |
| 판정 연출(지목) | 1 | 20초 | 20초 |
| 엔딩·도장 | 1 | 30초 | 30초 |
| **합** | | | **약 2분 10초** |
- 연출 간소화 켬/모션 줄이기 켬이면 약 1분 이하.

### 8-4. 글자·입력 속도
- 3단계(보통 36자/초 · 빠름 80자/초 · 즉시). 한 탭 = 현재 줄 완성, 한 번 더 탭 = 다음 줄. 연타해도 줄을 건너뛰지 않는다(한 번에 한 줄).
- 2회차 이상 + "읽은 대사 빠르게" 켬이면 `meta.readLines`에 있는 줄은 즉시 표시.
- 자동 넘김(Auto)은 제공하지 않는다. 대신 "탭 한 번에 한 줄" 리듬을 유지한다.
- 길게 눌러 빨리감기(P1): 의사결정 지점(제시·선택)에서 자동 정지.

### 8-5. 세션 중간 이탈 대응
- 플레이 시간(`playMs`)은 **탭이 보일 때만** 센다(`visibilitychange`). 타이핑은 숨김 시 일시 정지.
- 모든 변경이 자동 저장되고(시스템 3-9) 화면 앵커가 저장되므로, 닫았다 열면 같은 줄·같은 점으로 돌아온다.
- 장시간 방치 후 복귀: 대사 박스 한가운데 "계속하려면 탭" 한 줄(진행 중이던 줄 다시 표시).

### 10-2. 스크린 리더
- 타이핑 연출은 `aria-hidden`이고, 같은 문장 전체가 시각 숨김 텍스트로 먼저 있다(글자 하나씩 읽히지 않게).
- 대사 박스는 `role="log"`로 새 줄이 추가될 때만 읽는다. 화자 이름이 앞에 붙는다.
- 증언 줄 목록은 `ol`, 줄 점은 `aria-current`/상태 텍스트, 깨진 줄은 "깨짐, 정정: …".
- 평면도·장면 SVG는 `aria-hidden`이고, 목록·레일이 접근 경로다.
- 시트: `role="dialog" aria-modal="true"`, 제목 연결, 포커스 트랩(`/gung`의 BottomSheet 패턴 참조).

### 10-3. 색 · 대비 요구 (UI팀 인계)
