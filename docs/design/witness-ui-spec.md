## 0. 플레이 모드 확인 (PM 질문 답)

**이 게임은 처음부터 1인 전용이다.** 혼자 즐기는 모드가 곧 게임 전체이고, 다인용 모드는 없다.
- /gung(술자리, 방 코드·초대·동기화)과 가장 크게 다른 점이다. 이 스펙에는 방 코드, 초대 링크, 역할 배정, 방장 컨트롤, 다인 동기화 UI가 **하나도 없다.**
- 저장은 localStorage(`witness:v1:run`·`meta`)이고 이어하기가 있다. 한 판 20~30분, 2회차는 사건 소개·튜토리얼 건너뛰기와 읽은 대사 빠른 넘김이 있다.
- 타이틀에 칩 하나를 둔다: "혼자 · 약 25분". 처음 보는 사람이 1인용인지 바로 알 수 있게 한다.
- 「형사 모드」(P1)는 난이도 모드이지 다인 모드가 아니다. 지금은 토큰·props 확장 지점만 열어 둔다(§2-5, §5-2).

## 1. 비주얼 콘셉트 — 「물비늘타워 41층, 비 오는 밤」

**한 줄**: 폭우가 치는 한강변 펜트하우스. 통유리 밖은 번진 도시 불빛, 안은 스마트홈 조명과 기기 화면이 만든 네온빛. UI 자체가 이 집의 홈 허브 태블릿처럼 보인다.

### 1-1. 시각 언어 4가지
1. **유리(Glass)**: 대사창·시트·수첩은 반투명 유리 패널(블러 + 얇은 밝은 테두리 + 상단 하이라이트). 통유리 창과 같은 재질이라 장면 위에 자연스럽게 얹힌다.
2. **네온(Neon)**: 정보와 상태는 네온 라인·글로우로만 표시한다(시안 = 또박이·정보, 앰버 = 행동·제시, 핑크 = NEW, 레드 = 오답·거부, 바이올렛 = 오판 정정, 골드 = 결정적). 장식용 네온은 만들지 않는다.
3. **스마트홈 UI 문법**: 로그 줄, 시각 칩, LED 링, 장치 상태 점(online), 이퀄라이저 바. 증거 카드는 증거 태그(펀치 구멍 + 번호), 시계는 강력팀 도착까지의 거리다.
4. **비**: 모든 화면에 가는 빗줄기 2겹(원경·근경) + 창에 맺힌 물방울. 분위기 담당일 뿐 정보를 가리지 않는다(대사창 위에는 비를 그리지 않는다).

### 1-2. 분위기 조명(스마트홈 앰비언트)
셸 배경의 큰 방사형 빛 색을 상황에 따라 바꾼다. 집의 스마트 조명이 반응하는 연출이다.

| `data-ambient` | 조건 | 색 |
|---|---|---|
| `calm` | 기본 | 시안 + 아주 옅은 핑크 |
| `tense` | 행동 ≤3 또는 신뢰도 ≤2 | 앰버 |
| `siren` | 행동 0 | 레드 (정적, 깜빡임 없음) |
| `clear` | 최종 지목 단계·완벽 해결 엔딩 | 골드 + 새벽 청색 |

### 1-3. 저작권 회피 선 (역전재판식 문법만 쓰고 표현은 새로 만든다)
| 쓰는 것 (장르 문법) | 쓰지 않는 것 (표현) |
|---|---|
| 증언 한 줄씩 넘기며 추궁, 증거 제시로 모순 돌파, 컷인 연출, 신뢰도 자원, 캐릭터별 오답 리액션 | 「이의 있음!」「잠깐 기다려!」 등 고유 문구, 굵은 기울임 말풍선 모양, 파랑·노랑 대형 말풍선 |
| 정면 상반신 초상 + 하단 대사창 | 손가락질 포즈, 법정(재판관석) 배경, 특정 캐릭터와 닮은 실루엣(뾰족 머리·특정 의상 조합) |
| 증거 제시 | 증거 수첩 레이아웃·아이콘 복제, 효과음·BGM 모사 |

우리 쪽 대체 표현: 컷인 = 네온 사선 스트립 + 유리 균열, 제시 = 증거 카드가 유리 벽에 **박히는** 연출(손가락질 없음), 문구는 자체 3종(「다시 말해 봐!」「증거 나간다!」「앞뒤가 안 맞아!」), 대사창은 말풍선이 아닌 홈 허브 패널, 도장은 홀로그램 골드 스탬프.

### 1-4. 유머 규칙
- 웃음은 세 곳에 몰아 둔다: 오답 리액션, 유머 핫스팟, 또박이의 눈치 없음. 그 밖의 UI(HUD·시트·버튼)는 진지하고 읽기 쉽게 둔다.
- 오답 리액션은 대사 한 줄 + 인물 표정(평소 유지 + 비웃음 오버레이)으로 끝낸다. 코믹 이펙트(눈 튀어나옴 등)는 쓰지 않는다. 사건이 살인이라 톤이 가벼워지지 않게 한다.
- 시신은 그리지 않는다(분필선 + 덮은 천만). 혈흔·상처 표현 금지.

### 2-2. 대비표 (손계산 근사치 — 구현 후 도구로 재검증)
| 조합 | 대비 |
|---|---|
| ink / bg | 약 17.5 : 1 |
| body / bg | 약 12.0 : 1 |
| muted / bg | 약 6.4 : 1, muted / surface-2 약 4.9 : 1 (하한. 이보다 어두운 면 위에 muted 금지) |
| cyan / bg 12.5, amber / bg 11.6, green / bg 12, violet / bg 7.4, pink / bg 6.4, red / bg 6.5 | 모두 4.5 이상 |
| ink-dark / amber 11.1, / cyan 12.0, / violet 7.1, / red 6.3, / pink 6.1 | **네온 채움 위 텍스트는 항상 ink-dark** (흰 글자 금지: 흰색 / pink 약 3.1 로 미달) |
| 화자 색 7종 / surface-2 | 모두 약 7 이상 (가장 낮은 `--wt-spk-s2` 로즈 약 7.1) |

대사창은 `--wt-glass-strong`(0.86)를 쓴다. 뒤 배경이 순백이어도 합성 후 대비가 약 7.9:1 이라 장면이 밝아도 가독성이 무너지지 않는다. 장식용 `--wt-glass`(0.68) 위에는 본문 텍스트를 올리지 않는다.

### 2-3. 화자 색 규칙
- 화자 색은 **식별 보조**일 뿐이다. 이름은 항상 텍스트로 쓴다.
- 4명의 용의자는 채도·명도 비중을 맞춘다(범인이 색으로 튀지 않게). 선우강·표준혁은 저채도 중성색, 하늘·미숙은 채도 있는 색으로 일부러 성별·나이·직업 인상만 갈랐다.
- 의미색(앰버·시안·그린 등)과 같은 계열이 겹치는 곳(시안 = 또박이)은 의도된 겹침이다. 그 외에는 화자 색을 버튼·상태 표시에 쓰지 않는다.

- **목록 보기**(접근성·빠른 탐색): 바텀시트에 줄을 세로로 모두 나열(번호·시각·본문 1줄 말줄임·상태). 탭하면 해당 줄로 이동. 스와이프를 못 쓰는 사용자의 대체 경로다.

### 5-13. VerdictFx (판정 연출) — 가장 중요한 연출 묶음

**A. 미니 컷인**(추궁·제시, 650ms)
- 화면 높이 38% 위치에 −8° 사선 스트립(높이 76px, 시안 → 투명 그라디언트 + 1px 밝은 윤곽)이 왼쪽에서 280ms 스윕 인 → 문구 hold → 220ms 아웃. 문구 Black Han Sans 28px, 흰색 + 시안 글로우. 추궁 = 시안 스트립 「다시 말해 봐!」, 제시 = 앰버 스트립 「증거 나간다!」.
- 제시: 스트립과 함께 고른 증거 카드가 아래에서 화면 중앙으로 올라와(scale .8 → 1, 240ms) 대기 → 판정 결과로 이어짐.

**B. BREAK 돌파 컷인**(전체 1100ms + 후속)
| 시각(ms) | 연출 |
|---|---|
| 0 ~ 90 | 히트스톱(화면 정지) + **화면 번쩍**(흰색 `--wt-flash-peak`→0, 90ms, 1회, ★ 돌파일 때만) |
| 0 ~ 240 | 증거 카드 위치에서 **유리 균열**이 방사(SVG 라인 8~10개, stroke-dashoffset 240ms, 시안 + 흰색) |
| 80 ~ 360 | 사선 스트립 스윕 인: 「앞뒤가 안 맞아!」 Black Han Sans `--wt-fs-cutin`, 흰 글씨 + 2px `--wt-ink-dark` 외곽 + 글로우. ★ = 골드 스트립, ◆ = 시안 스트립 |
| 120 ~ 480 | **화면 흔들림** `--wt-shake-amp` 6px, 5회 감쇠 360ms(◆는 3px) |
| 360 ~ 600 | 증거 카드가 깨진 증언 줄에 **쾅 박힘**(scale 1.25 → 1, 그림자 확대, `--wt-ease-slam` 220ms). 인물 표정 shock + 점프 |
| 700 ~ 1100 | 스트립 아웃, 증언 줄에 레드 취소선이 그어지고 「정정」 칩 + 정정 진술 등장 |
| 1100 ~ | 돌파 리액션 대사(≤4줄) |
| ★ 한정 +900 | 골드 홀로그램 스탬프 **「결정적」** 이 −8°로 쾅(scale 1.7 → 1, 360ms) + 파문 링 1회 + TrustMeter +1 골드 스윕 + 강한 진동 |
| 마지막 | 해금 토스트들(§5-16): 「새 증언」「주방에 새 단서」「증거 갱신: ○○ → 위조된 ○○」 |

◆ 일반 돌파는 번쩍·스탬프 없이 짧게(총 800ms), 회복도 없다.

**C. WRONG 오답**
- 증거 카드가 유리 벽에 부딪혀 튕겨 나옴(translateX ±10px 2회 + rotate ±3°, 260ms). 화면 **가장자리 레드 비네트** 펄스(알파 .35, 220ms — 전면 번쩍 아님). 흔들림 4px(가로만, 2회). TrustMeter 셀 파열. 인물 표정 평소 유지 + 비웃음(smirk) 오버레이, 오답 리액션 한 줄. 이어서 탐정 독백 「…헛다리였다.」
**D. HALF 반쯤 맞음**: 카드가 한 번 rotate ±2°로 떨리고 앰버 링이 1회 번짐(240ms). 감점·번쩍·흔들림 없음. 대사 「흔들린다… 그런데 딱 맞진 않는다.」
**E. REDIRECT 우회**: 카드가 옆으로 부드럽게 밀려나 반투명이 됨(260ms). 효과 없음. 인물 대사만.
**F. 사이렌(행동 0)**: 화면 좌·우 가장자리에 레드/시안 조명 바가 교대(주기 1.2s ≈ 0.83Hz, 3사이클 후 정지, 이후 레드 정적) + 하단 큰 자막 「사이렌이다.」. 번쩍임 기준(초당 3회 미만) 준수.
**G. 최종 판정 연출**: §5-15에서.

**접근성·안전 규칙**
- 번쩍임은 **1초에 1회 이하, 최대 불투명도 .55, 90ms 이내**. 적·청 교차 점멸은 초당 3회 미만. 전면 번쩍은 ★ 돌파와 최종 판정의 정답 칸에만 쓴다.
- 설정에 「화면 효과 줄이기」(`data-fx='reduced'`)를 둔다(기존 설정: 텍스트 속도·효과음·진동에 항목 1개 추가 — §10 이슈 4). `prefers-reduced-motion: reduce` 이면 자동으로 reduced.
- 스크린리더: 돌파·오답·반쯤 맞음 결과는 `role="alert"` 영역에 문장으로 읽어 준다(「모순 돌파. 정정: 9시 40분 이후엔 서재에 없었습니다」).
- 진동: 오답 `[40]`, ◆ 돌파 `[20,30,40]`, ★ 돌파 `[30,40,30,40,90]`, 사이렌 `[60]`. 설정이 꺼져 있으면 무음.

**reduced 모드 동작 대응표**

|---|---|---|

### 5-15. AccuseFlow (지목 3단계 + 3칸)
**1단계 범인 선택**: 2×2 격자, 카드 약 160×208. 초상(평소 표정) + 이름표 + 직업 한 줄. 5번째로 또박이 카드를 아래에 같은 크기로 놓되 캡션 「증인」을 muted로 단다(숨기지 않는다). 선택 = 앰버 링 + 나머지 dim. 푸터 [이 사람으로](56). 또박이를 누르면 이스터에그 대사(한결 「스피커를 체포할 순 없습니다」) 후 다시 고르게 하고, 업적 토스트를 띄운다. 페널티 표시 없음.

**2단계 증거 3칸**: 세로 3열 `수단 / 기회 / 동기`. 칸 108×140, 점선 윤곽 + 상단 아이콘(수단 Hammer / 기회 DoorOpen / 동기 Flame) + 라벨. 채워지면 EvidenceCard S가 들어가고 우상단 「바꾸기」 48. 칸을 누르면 증거 고르기 시트(slot 모드). 푸터 [이대로 강력팀에 넘긴다?](56, 3칸이 다 차야 활성). 같은 증거를 두 칸에 넣을 수 없다(시트에서 비활성).

**지목 경고 `accuseWarn`**: 중앙 모달. 한결 초상(sweat) 120px + 대사 2줄(Pretendard 17) + [넘긴다](보조) / [수사 계속](주). 행동 0 강제 지목에서는 생략.

**3단계 확인 모달**: 「이대로 강력팀에 넘긴다?」 + 보조 문구 「제출 후에는 고칠 수 없어요.」 [취소](보조, 왼쪽) · [넘긴다](주). 두 버튼 사이 간격 24px(반대 의미).

**최종 판정 연출**(전체 약 5초, 탭으로 빨리 감기 가능):
1. 암전 비트 0.5s, 배경 `data-ambient='clear'` 전환.
2. 호명: 범인(선택된 인물) 초상이 무대 중앙으로 커짐(scale .9 → 1) + 대사 「범인은— 표준혁, 당신이다.」 (인물 이름은 선택에 따라 치환).
3. 수단! → 기회! → 동기! 순으로 칸 카드가 화면 중앙에서 하나씩 **쾅**(칸당 1000ms). 맞은 칸: 카드 골드 글로우 + 그린 체크 + 초상이 한 단계 무너짐(normal → sweat → shock → break 순). 틀린 칸: 카드 레드 균열 + 인물 비웃음 오버레이 + 대사 「그게 증거라고?」류. 맞은 칸마다 번쩍 1회(최종 판정만 허용). 칸 연출이 1000ms 간격이라 번쩍은 초당 1회를 넘지 않는다.
4. 결과 컷 → 엔딩 카드로.
오인 체포(범인 오답)는 칸 판정 없이 선택된 인물이 어이없어하는 표정 연출만.

**접근성**
- [ ] 모든 텍스트 4.5:1 이상(§2-2). 네온 채움 위 글자는 `--wt-ink-dark`.

- [ ] 색만으로 전하지 않음: 신뢰도(숫자·윤곽), ★(채움/윤곽), 상태 칩(아이콘 + 글자), LED(이퀄라이저·문구), 정답/오답(체크·균열 + 글자).
- [ ] 텍스트 200% 확대에서도 패널 스크롤·버튼 줄바꿈으로 깨지지 않음.
- [ ] 번쩍임: 1초 1회 이하, 알파 ≤ .55, 90ms; 적·청 교대 초당 3회 미만; 「화면 효과 줄이기」·`prefers-reduced-motion` 지원.

**성능**
- `backdrop-filter`는 화면당 동시 2곳(대사창 + 시트)까지. 미지원은 불투명 `--wt-surface` 폴백.

- 폰트 추가 로드 3종(Black Han Sans·Nanum Gothic Coding·Gaegu) + Gowun Batang 중복(캐시). `font-display: swap`.
- `will-change`는 애니메이션 중에만.

**반응형**
- 360 / 375 / 390 / 430px 세로가 기준 점검 폭. 320px는 대사창 4줄 확장을 확인. 640px landscape 2열. 1024px 이상 콘텐츠 560px.

1. **핫스팟 좌표 충돌 2곳**(히트 영역 48px 겹침). 그림 높이 640px 기준 1% ≈ 6.4px.

2. **`Hotspot.hiddenUntilUnlock` 필드** 제안: L0.h5(먼지통)처럼 추궁 플래그로 열리는 핫스팟은 잠금 아이콘으로 미리 보여 주면 단서가 되므로, 작가가 `lockedLabel`을 안 쓴 해금형 핫스팟은 해금 전까지 그리지 않는다.
3. **Face 5종 → 3종 매핑**(§6-2): 설계서 6-3 `Face`에 `angry`가 없는데 사건서가 쓴다. 타입에 `angry` 추가를 권장하고, 그림은 3종 + 오버레이로 처리한다.

7. **OG 파라미터 확장**: 시스템 설계서 예시(`g`,`s`,`e`)에 `r`,`k`,`h`,`v` 선택 파라미터 추가(§5-16). 모두 열거·정수.
8. **테마**: 1차 릴리스는 다크 전용으로 두고 새벽 모드(§2-4)는 토큰만 준비. 설정 노출 여부는 PM 결정.
9. **폰트 3종 추가 로드**(Black Han Sans·Nanum Gothic Coding·Gaegu): Google Fonts가 한글을 unicode-range 조각으로 보내 쓰는 글자만 내려오지만, 첫 방문 LTE에서는 컷인 문구가 폰트 교체로 깜빡일 수 있다. 폴백(Black Han Sans → Pretendard 800)이 이미 정해져 있으므로 깜빡임이 크면 프론트가 Black Han Sans 한 종에 한해 컷인 3문구용 `text=` 서브셋 CSS를 별도로 먼저 로드하는 것을 검토한다.
