# 세자 독살 사건 (/gung) — UI 디자인 스펙

작성자: @UI디자이너 · 대상 라우트: `src/app/gung/` (Next.js 14 App Router)

## 레포 규칙 준수 체크

- 스코프 루트 클래스 `.gu-shell` 1개 — 모든 스타일은 이 클래스 하위에서만 유효. `src/app/gung/gung.css`를 `src/app/gung/layout.tsx`에서만 import.
- 디자인 토큰은 전부 `.gu-shell { --gu-*: ...; }` CSS 변수로 선언. `globals.css` / 루트 `layout.tsx` / `tailwind.config.ts` 무수정.
- 본문 서체 **Pretendard Variable**, 숫자 모노 **JetBrains Mono**는 루트 레이아웃이 이미 전역 로드 중 → `gung.css`에서 추가 로드 0. 사극풍 디스플레이/손글씨 서체만 라우트 스코프로 신규 로드(아래 §3).
- 아이콘은 `lucide-react`. 역할 패·장소 등 사극 전용 실루엣/문양은 커스텀 인라인 SVG(§5)로 별도 제작 — lucide와 톤(선 굵기 1.75, 라운드 조인) 맞춤.
- 다크 전용(라이트 모드 없음) — `color-scheme: dark`. 어두운 술자리 조명을 기본 전제로 모든 대비값을 산출(§2 대비 노트 참고).

## 1. 비주얼 콘셉트 — "밤의 궁궐: 먹·단청·한지·촛불"

**한 줄 콘셉트**: 소등한 술자리 테이블 위, 폰 화면 하나가 촛불처럼 밝혀진 궁궐의 밤. 짙은 먹색 어둠 속에 한지 질감의 카드와 단청(丹靑) 오방색 포인트, 금박 느낌의 강조선이 올라온다.

- **먹(墨) — 배경**: 거의 무채에 가까운 짙은 남흑색을 베이스로 쓴다. 완전한 블랙(#000)은 쓰지 않고 아주 옅게 푸른/보라 기운을 섞어 "밤하늘·기와 그늘" 느낌을 낸다. 저조도 술자리 환경에서 화면 밝기를 낮춰도 요소 간 위계가 무너지지 않도록, 배경↔표면↔카드 3단만 쓰고 각 단의 명도차를 크게 벌린다(§2 참고).
- **한지(韓紙) — 표면**: 비밀 카드·역할 패 뒷면·단서 카드처럼 "손에 쥐고 읽는" 요소는 다크 배경 위에 떠 있는 밝은 한지색 패널로 반전시킨다. 어둠 속 유일한 밝은 사물 = "지금 내가 읽어야 하는 것"이라는 시각적 우선순위를 만든다.
- **단청(丹靑) — 포인트**: 처마 아래 색동인 적(朱)·청(靛)·황금(金)·녹(綠)을 역할/상태 구분색으로만 제한적으로 쓴다. 장식이 아니라 정보(라운드/장소/공개 상태/위험)를 구분하는 용도로만 사용 — 같은 요소는 같은 색, 예외 없음.
- **촛불/등롱 — 광원**: 주요 CTA·활성 타이머·진행 중 라운드에는 미세한 촛불 글로우(퍽 퍼지는 warm glow, box-shadow)를 줘서 "지금 밝혀진 곳"을 눈으로 바로 찾게 한다. 장식 애니메이션(흔들림)은 §6 모션 원칙에 따라 아주 미세하게, reduced-motion에서는 정지.
- **낙관/도장**: 결정적 순간(공개 선택, 지목 확정, 범인 발표)에는 붉은 인주색 도장이 "쾅" 찍히는 비주얼로 되돌릴 수 없는 결정감을 준다.
- **대비 우선 원칙**: 취해서 조명이 어둡고 화면을 대충 보는 상황을 기본 사용 조건으로 가정. 모든 텍스트/버튼은 WCAG AA(4.5:1) 이상, 핵심 CTA·타이머 숫자는 7:1 이상을 목표로 한다. 질감(한지 결, 먹 번짐)은 항상 배경 데코레이션에만 쓰고 텍스트 레이어에는 노이즈를 얹지 않는다.

| 디스플레이(워드마크, 사건명, 카드 타이틀) | **Song Myung** (송명체) | 훈민정음 해례본에서 모티프를 딴 구글 폰트. 붓끝이 살아있는 획으로 "조선풍" 정체성을 가장 강하게 드러냄. 레귤러(400) 단일 웨이트라 큰 사이즈 위주로 사용. |
| 디스플레이 보강(볼드 필요 영역 — 역할명, 큰 버튼 라벨, 결과 카드 숫자 옆 텍스트) | **Nanum Myeongjo** (700/800) | Song Myung에 볼드가 없어 명조체 계열로 무게감 보완. 격식 있는 느낌 유지하며 가독성 확보. |
| 손글씨(말투 예시, 귓속말 메모, 서명/낙관 옆 캡션) | **Nanum Pen Script** | 레포 내 `/rewind`, `/zombie`에서 이미 쓰인 한글 지원 손글씨체 — 전례 검증됨. "개인 미션" 같은 비밀스러운 메모 느낌에 사용. |
| 본문 | **Pretendard Variable** | 루트 레이아웃 전역 로드 — 추가 로드 0. |

## 4. 컴포넌트 스펙

### 4.1 비밀 카드 — "꾹 눌러 보기"

가장 많이 쓰이는 프라이버시 패턴(역할 패 뒷면, 개인 미션에도 재사용).

- **봉인 상태(기본)**: `--gu-surface` 배경의 카드. 중앙에 호패 봉인 문양(낙관 원형 SVG, `--gu-seal`) + "누르고 있으면 보여요" 캡션(Nanum Myeongjo) + lucide `Hand` 아이콘. 테두리는 `--gu-line-2` 1px, 옆사람 시선 차단을 돕는 안내 한 줄 추가: "옆자리에 보이지 않게, 손으로 가리고 꾹".
- **인터랙션**: `onPointerDown` 즉시 카드 테두리에 `--gu-gold` 진행 링(도장을 누르는 압력처럼 채워짐, 450ms)이 돌고, 완료 시점에 한지색으로 반전되며 내용이 드러남(먹 번짐 와이프 트랜지션, `--gu-dur-reveal`의 절반 정도). 홀드 중 내용 유지, `onPointerUp`/`onPointerCancel`/`onPointerLeave`/탭 전환(`visibilitychange`)에서는 **페이드 없이 즉시 재봉인**(엿보기 방지가 장식성보다 우선 — 지연 없는 하드 컷).
- **크기/탭 영역**: 최소 높이 220px, 좌우 여백 16px, 카드 전체가 프레스 영역(의도치 않게 모서리만 눌러도 반응).
- **reduced-motion**: 진행 링·와이프 생략, 홀드 임계치(450ms) 도달 시 상태만 즉시 토글.

### 4.2 단서 카드 — 장소 · 라운드 · 공개 도장

- **헤더**: 좌측에 라운드 뱃지(`R1`/`R2`/`R3`, 금박 pill) + 장소 아이콘(§5) + 장소명(Song Myung, 18px).
- **본문**: 단서 텍스트, Pretendard 16px, 한지색(`--gu-paper`) 패널 위 `--gu-ink-on-paper`.
- **공개/비공개 토글**: 하단 큰 스위치 버튼 2개(세그먼트, 각 52px 높이). "공개" 선택 시 카드 전체 보더가 `--gu-gold`로 바뀌고 모서리에 붉은 인주 도장이 -8deg 기울어진 채로 "쾅"(scale 1.4→1, 120ms overshoot, `--gu-ease-bounce`) 찍힌다 — 도장 문구는 "공개". "비공개" 선택 시 `--gu-muted` 점선 보더 + 작은 봉인 아이콘만. 공개로 설정하면 카드 상단에 "소리 내어 읽어주세요" 캡션이 뜬다(이 카드는 테이블에 공개하고 말로 읽는 용도이므로 비밀카드의 꾹 눌러보기 패턴을 쓰지 않음).
- **크기**: 최소 높이 180px, 카드 리스트는 세로 스택, 라운드 전환 시 이전 라운드 카드는 접혀서(accordion) 아래로 쌓인다.

### 4.3 역할 패 — 호패(號牌) 모티프

- **형태**: 세로형 나무 패, 상단 중앙에 끈 구멍(작은 원형 SVG 홀) 장식. 모서리 라운드는 상단만 크게(`--gu-radius-xl`), 하단은 `--gu-radius-sm`로 패 특유의 비대칭 실루엣.
- **앞면(항상 공개 — 공개 프로필)**: 나무 질감 그라디언트 배경(`--gu-surface`→`--gu-surface-2`), 역할 실루엣 아이콘(§5, 대형), 역할명(Song Myung 22px), 말투 예시 한 줄(Nanum Pen Script, 손글씨 메모 카드처럼 살짝 기울여 부착).
- **뒷면(비밀 — 꾹 눌러 보기 패턴 재사용, §4.1)**: 한지 패널로 반전. 섹션별로 작은 인장 아이콘 + 라벨로 구분: "비밀" / "그날 밤 동선" / "거짓말해도 되는 것" / "개인 미션". 범인 역할만 "그날 밤 동선" 섹션 앞에 `--gu-red` 작은 점(위험 신호, 텍스트로는 "범행" 단어 노출 안 하고 색으로만 암시해 화면 너머로 유추되는 것을 최소화).
- **전환**: 앞↔뒤는 "뒤집어 보기" 버튼(하단 고정, 52px) 탭 시 3D `rotateY` 플립(`--gu-dur-slow`), 뒷면 진입 시에는 추가로 §4.1의 홀드 재봉인 로직이 겹쳐 적용(플립 자체는 눌러야 일어나지 않고, 뒷면 "내용 보이기"만 꾹 눌러야 함 — 2단 보호).
- **비율**: 가로:세로 ≈ 1 : 1.62(호패 실측 비례감), 모바일에서 화면 폭의 84%.

### 4.4 타이머 — 향(香) 타는 모양

두 가지 변형, 용도에 따라 선택:

- **선택 타이머(2분, 각자 장소 고르는 시간)**: 원형 코일향(모기향 형태) SVG. 외곽에서 중심으로 타들어가는 나선 path를 `stroke-dasharray`로 "탄 부분(회색 재, `--gu-muted`)"과 "안 탄 부분(쑥색, `--gu-green` 톤 다운)"으로 나눠 표현, 끝에 작은 연기 한 줄(ambient, §6). 중앙에 `--gu-font-mono` 숫자 오버레이.
- **토론 타이머(7분, 발언/토론)**: 세로 향 스틱 + 끝에 불씨(ember, `--gu-candle` 글로우). 좌측에 분 단위 눈금 틱. 타들어간 길이만큼 향이 짧아지는 `height` 트랜지션(`transition: height 1s linear`).
- **경고 상태**: 남은 시간 20% 이하 → 불씨/코일 색이 `--gu-red`로 전환 + 촛불 깜빡임 펄스(§6, reduced-motion에서는 고정 색상 전환만).
- **방장 컨트롤**: 재생/일시정지/+30초/스킵 — 전부 `--gu-tap-primary`(64px) 큰 버튼, 버튼 간 간격 최소 16px(음주 상태 오조작 방지).

### 4.5 라운드 진행 바

- 궁궐 회랑 기둥 모티프: 기둥 4개(R1 / R2 / R3 / 진상공개) 아이콘이 가로로 나열. 지난 기둥은 금박 채움(`--gu-gold`), 현재 기둥은 촛불 글로우 펄스(`--gu-shadow-glow`), 미래 기둥은 `--gu-line-2` 아웃라인만.
- 화면 상단 sticky, 높이 56px, 배경은 `--gu-bg-2`에 하단 1px `--gu-line` 보더.

### 4.6 큰 버튼

| 종류 | 배경 | 텍스트 | 높이 | 용도 |
|---|---|---|---|---|
| Primary | `--gu-gold` | `--gu-ink-on-paper` | 64px | 다음 단계, 제출, 확정 |
| Secondary | 투명 + `--gu-line-2` 보더 | `--gu-ink` | 52px | 보조 동작 |
| Danger/되돌리기 | 투명 + `--gu-red` 보더 | `--gu-red-strong` | 52px | 라운드 되돌리기, 리셋 |
| Ghost(아이콘 전용) | 투명 | `--gu-muted` | 48px(정사각) | 헤더 보조 아이콘 |

- 파괴적 동작(라운드 넘기기 취소, 역할 재배정 등)은 탭 1회로 끝나지 않고 바텀시트 확인("정말요?" + 취소/확정 2버튼)을 반드시 거친다.
- "되돌리기"는 헤더 좌상단에 항상 고정 노출(48px), 화면 전환 중에도 위치 불변 — 취한 상태에서 어디서든 같은 자리.
- 모든 버튼 간 최소 간격 16px, 인접 버튼의 의미가 상반될 때(확정 vs 취소)는 24px로 확대.

### 4.7 투표 화면 — 동시 지목

- **카운트다운 비트**: 전체화면 오버레이, "셋.. 둘.. 하나"를 Song Myung 대형 숫자(`--gu-fs-display-xl`보다 큰 전용 사이즈, 80px)로 순차 노출 후 암전 0.3초 → 투표 입력 화면 전환.
- **지목 그리드**: 역할 6개를 2×3 그리드로, 각 타일 96×120px 이상. 타일은 역할 패(§4.3) 축소판(실루엣 아이콘 + 역할명)으로 재사용해 일관성 유지.
- **모드 A(방장 집계)**: 손가락 세기를 보고 방장이 해당 타일을 탭할 때마다 숫자 뱃지가 올라감(+1마다 가벼운 pop, `--gu-ease-bounce`). "집계 마감"은 Primary 버튼.
- **모드 B(각자 투표)**: 1인 1표, 제출 시 자신 화면에 `--gu-seal` 도장 "제출완료"가 찍히고 입력 잠김. 방장 화면에는 금박 바 차트로 실시간 집계(막대 길이 = 득표, `--gu-gold` 채움).
- 두 모드 모두 제출 전 "다시 고르기"로 변경 가능, 제출 후에는 확인 바텀시트 없이 즉시 잠금(이 단계는 긴장감이 핵심 — 머뭇거림 UI 최소화).

### 4.8 진상 공개 연출 — 두루마리 펼침

1. **암전 비트**: 전체 화면 `--gu-bg`로 전환, "그날 밤..." 한 줄(Song Myung, 중앙) 0.6초.
2. **두루마리 펼침**: 상하 두 개의 축(scroll cap) 사이로 한지 패널이 세로로 펼쳐짐(`height: 0 → auto` 또는 `clip-path` 기반, `--gu-dur-reveal`). 펼쳐진 두루마리 안에 타임라인(시각별 사건 재구성) 항목이 위→아래로 0.12초 간격 stagger fade-in.
3. **범인 지명 도장**: 타임라인 마지막에 범인 이름 위에 `--gu-seal` 색 도장이 회전 -6deg로 "쾅" 찍힘(§4.2와 동일한 도장 모션 재사용 — 일관성).
4. **요약**: 결과 요약 텍스트(Nanum Myeongjo bold) + "다음: 결과 카드 보기" Primary 버튼.
- **reduced-motion**: 펼침 애니메이션 생략, 두루마리는 이미 펼쳐진 상태로 즉시 표시, 타임라인은 stagger 없이 한 번에, 도장은 모션 없이 최종 상태로 바로 표시.

### 4.9 결과 카드 (공유 이미지, 1200×630)

카카오톡 공유 썸네일/OG 이미지 규격.

- **캔버스**: 1200×630, 세이프존 1200×600(상하 15px씩은 플랫폼 크롭 대비 여유, 핵심 텍스트는 이 안에만 배치).
- **배경**: `--gu-bg` 그라디언트 + 상하좌우 40px 폭의 단청 문양 띠 프레임(구름문/파도문 반복 패턴, `--gu-gold` 10% 투명도).
- **상단 (y 40~140)**: kicker "오늘의 사건 기록"(`--gu-muted`, 20px) + 워드마크 "세자 독살 사건"(Song Myung, 56px, `--gu-ink`).
- **중앙 (y 160~420)**: 결과 스탬프 — "검거 성공"(`--gu-green`) 또는 "범인 도주"(`--gu-red`) 도장 그래픽, -8deg 회전, 지름 약 180px. 좌우로 6개 역할 실루엣 미니 아이콘을 늘어놓고, 정답을 맞힌 플레이어 아이콘에는 금박 테두리 링 추가.
- **하단 (y 440~590)**: "N명 중 M명이 진범을 찾아냈다"(Nanum Myeongjo 800, 32px) + 내 역할/개인 미션 성공 여부 chip(pill, `--gu-surface` 배경).
- **최하단 (y 600~630)**: 워터마크 "project-orsrw.vercel.app/gung"(JetBrains Mono, 13px, `--gu-muted`).
- **내보내기**: 2배 스케일(2400×1260)로 렌더 후 다운스케일 — 작은 한글/도장 디테일이 카카오 썸네일 압축에서도 뭉개지지 않게.

## 5. 장소 7곳 · 역할 6명 — 아이콘/일러스트 방향

**공통 스타일 가이드**: 24×24 viewBox, `stroke-width: 1.75`, `stroke-linejoin: round`, `stroke: currentColor`(역할/상태 컬러를 그대로 상속). 두 가지 variant 제작 — ①UI 전용 outline(리스트/뱃지 등 작게 쓰일 때), ②카드/결과화면용 filled-silhouette(실루엣 내부를 단색 채우고 단청 문양을 흰 선으로 음각). 실존 인물·초상 묘사는 금지 — 전부 신분을 드러내는 소품/실루엣으로 추상화.

### 장소 7곳 (제안안 — 기획팀 최종 확정 대기)

| 장소 | 아이콘 모티프 |
|---|---|
| 대전(정전) | 용상 등받이 실루엣 + 섬돌 계단 2단 |
| 동궁전(세자 침소) | 접은 병풍(지그재그 3단) + 촛대 1개 |
| 수라간(주방) | 솥 실루엣 + 주방칼 교차 |
| 내의원(약방) | 약절구 + 매달린 약봉지 끈 |
| 후원 연못가 | 정자 지붕 + 물결문 2줄 |
| 행랑(내관 처소) | 회랑 기둥 3개 반복 패턴 |
| 혼전(빈소) | 향로(연기 한 줄) + 위패 실루엣 |

### 역할 6명 (제안안 — 5명은 브리프 확정, 6번째는 기획팀 최종 확정 대기)

| 역할 | 아이콘 모티프 |
|---|---|
| 중전 | 큰 가체(비녀 가로획) + 봉황 꼬리깃 문양 |
| 후궁 | 작은 가체 + 매화 가지 문양 |
| 내관 | 사모(관모) + 손에 든 두루마리 |
| 어의 | 침통(바늘통) + 약주머니 |
| 상궁 | 족두리(소형) + 곳간 열쇠 고리 |
| (6번째, 제안: 별감·호위무사) | 전립(군모) + 환도(검) 실루엣 — *기획팀 콘텐츠 확정 후 아이콘 모티프 최종 조정* |

역할 아이콘은 역할 패(§4.3) 앞면 대형 실루엣과 투표 그리드(§4.7) 소형 아이콘 양쪽에 동일 SVG를 스케일만 바꿔 재사용 — "같은 요소는 같은 스타일" 원칙.

## 6. 모션 원칙

- **등장 기본값**: fade + rise 8~12px, `--gu-dur-base`(220ms), `--gu-ease`. 리스트 아이템은 60~120ms stagger.
- **서사 연출(두루마리 펼침, 도장 찍기, 암전 비트)**: 유일하게 `--gu-dur-slow`~`--gu-dur-reveal`(420~600ms)까지 허용 — 게임의 극적 긴장감을 담당하는 순간이므로 길이를 아낀다. 단, 이것도 reduced-motion에서는 즉시 최종 상태.
- **앰비언트 루프(촛불 글로우, 향 연기, 금박 쉬머)**: `opacity`/`transform: scale` 전용, 2.4~4s 느린 주기, `ease-in-out alternate`. 레이아웃에 영향 주는 속성(width/height/margin) 애니메이션 금지 — 리플로우 비용 방지.
- **확인/긴장 비트(투표 카운트다운, 집계 뱃지 pop)**: `--gu-ease-bounce`로 짧고 명확하게(120~180ms) — 애매하게 느리면 술자리 템포를 깬다.
- **엿보기 방지 전환(비밀 카드 재봉인)**: 애니메이션 없이 즉시 하드 컷. 보안 목적 전환은 모션 원칙의 예외 — 항상 속도가 장식성보다 우선.
- **`prefers-reduced-motion: reduce`**: 레포 공통 패턴을 그대로 적용.

```css
@media (prefers-reduced-motion: reduce) {
  .gu-shell *, .gu-shell *::before, .gu-shell *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    animation-delay: 0s !important;
    transition-duration: 0.01ms !important;
  }
}
```

reduced-motion에서도 기능/정보 손실은 없음을 원칙으로 한다: 두루마리는 펼쳐진 "최종 상태"로, 도장은 찍힌 "최종 상태"로, 타이머 경고는 애니메이션 대신 고정 색상 전환으로 즉시 보인다.

## 구현 핸드오프 참고 (UI 범위 밖, FE 참고용)

- **Wake Lock**: 가능한 브라우저에서 활성화 시, 헤더에 작은 촛불 아이콘(점등 상태) 뱃지로 "화면 꺼짐 방지 켜짐"을 알리는 것을 권장 — 별도 설명 텍스트 없이 아이콘 on/off만.
- **localStorage 복구**: 새로고침 후 상태 복원 시, 화면 상단에 작게 "이어하는 중..." 토스트(`--gu-surface` 배경, 1.5초 후 자동 소멸)를 1회 노출해 사용자가 "진행이 날아갔나" 불안해하지 않도록 한다.
- **카톡 인앱 브라우저**: 공유 카드/결과 카드 생성 시 `html2canvas` 등으로 클라이언트 렌더링한 PNG를 Kakao JS SDK `sendDefault`의 이미지로 사용하는 경로를 가정(인앱 브라우저의 파일 다운로드 제약 고려, 공유 우선 / 다운로드는 보조 버튼).
