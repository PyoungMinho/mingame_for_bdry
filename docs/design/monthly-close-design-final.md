## 0. 한 장 요약

1. **UX 흐름 + UI 시각을 그대로 채택**하고, 서로 남긴 열린 질문(UX §12, UI §12)과 UI가 방향서와 다르게 정한 10건(UI §11)을 모두 닫았다(§1).
2. **ESC는 언제나 숨기기다.** 드롭다운이 열려 있어도 먼저 접지 않고 바로 숨긴다(접힌 상태로 숨는다). 취소는 ✕, [취소], 같은 버튼 다시 누르기, 바깥 클릭뿐이다.
3. **F10 대신 `/` 키를 "명령 이동 키"로 쓴다.** 맥 노트북에서 F10은 기본이 음소거 키이고, 윈도우 브라우저도 F10을 메뉴 포커스로 먼저 가져갈 수 있다. `/`는 시트 앱이 메뉴 키로 써 온 키라 위장에도 맞다. F10은 동작하는 곳에서만 쓰는 별칭이다.
4. **이름 상자 Enter = 즉시 반영(발사)을 승인한다.** 좌표를 타이핑하는 것 자체가 "선택"이다.
5. **숨어 있는 동안 게임 단서 0개를 유지한다.** 차례인 사람이 숨으면 시계가 멈추므로(120초 한도) 단서가 없어도 손해가 없다. 돌아오면 상태줄 5초 요약으로 보완한다.
6. **파비콘은 "접힌 모서리 없는 표 아이콘"으로 바꾼다.** UI 원안(접힌 모서리 + 칸)은 구글 시트, 대체안(접힌 모서리 + 가로줄)은 구글 문서 실루엣과 가깝다. 둘 다 버리고 가장 일반적인 표 그림을 쓴다(§6-4).
7. **크롬 스크롤바 문제는 `scrollbar-color`를 빼는 것으로 푼다.** 그러면 크롬·엣지·사파리 모두 우리 12px 각진 막대가 적용되고, 파이어폭스만 OS 기본 막대다. 실기 확인은 QA 항목이다.
8. **직급이 들어간 문구 4개는 모두 유지한다.** 대신 "직급 문구 수위 기준" 6개를 확정해 앞으로 쓸 문구도 같은 기준으로 판정한다(§8-3). "부장님 법카 내역"은 연습과 회계 첫 판에 고정 노출한다.
9. **개발 순서는 셸 먼저.** D1 끝에 PM 눈테스트(G0-5 미리보기)용 스크린샷 묶음을 낸다(§10-2).
10. **문구 팩 JSON은 페이지개발자가 D1에 만든다.** 원문은 UX §9 + 이 문서 §8의 수정·추가분이다. 개발자는 새 문구를 쓰지 않고 옮기기만 한다(§10-3).

## 4. 셸 레이아웃 최종

### 4-1. 크롬 (UI §2-1·§1-4 채택)

위에서부터 상단바 40 / 메뉴줄 28 / 도구줄 36 / 이름 상자·수식 입력줄 28 / 창 머리 띠 24 / 열 머리글 24 / … / 시트 탭 28 / 상태줄 24 = 고정 232px. 창 안쪽 높이 640px에서 판 영역 17행이 보인다. 높이 600px 미만이면 메뉴줄을 접는다(UI §1-4).

- 상단바: 표 아이콘 20px + 파일명 + ☆(장식) + `버전 기록 2:1`(장식, 전적) / 오른쪽 편집자 원 2개(이니셜만) + `공동 편집 중` + [공유].
- 메뉴줄: 8개 중 **파일·도움말만 동작**(UX U10). 파일 = `새 문서`(홈으로), `문서 닫기`(W·P는 바로 나감, B는 기권 팝오버). 연습에서는 `연습 종료`. 도움말 = `인수인계서`(규칙 3줄 팝오버, 홈 안내와 같은 문구, 등급 3).
- 도구줄: 장식 아이콘 + 기능 2개([Σ(n)], [의견 남기기 ▾]). 기능 버튼도 장식과 같은 모양(UI §2-1).
- 수식 입력줄: 값 또는 수식만, 결과값 표시 없음.

## 9. 프론트엔드 전달 사항

### 9-1. 최종 키 표 (방향서 §5-4 + A1~A6)

| 화면 | Tab / Shift+Tab | ESC | 창 이탈 | `/` (F10 별칭) | Enter | 복귀 |
|---|---|---|---|---|---|---|
| 홈 | 표준 이동 | 없음 | 없음 | 글자 | 표준 | — |
| 입장 대화상자 | 입력 칸 이동 | **숨기기** | 숨기기 | 입력칸이면 글자 | [열기] | 게임 탭 클릭 |
| 시트(대기·배치·대전·결과 탭)·연습 — 입력칸·한글 조합·드롭다운·팝오버·힌트 고르기 중에도 | **숨기기** | **숨기기** | 숨기기(돌아와도 유지) | 명령 이동 모드(검산 입력칸 안에서는 무시) | 발사·확정 | 게임 탭 클릭 |
| 숨기기 시트 | 다음 칸 / 이전 칸 | 편집 취소 | 그대로 | 글자 입력 | 확정 후 아래 | 게임 탭 클릭 |

- Ctrl·Alt·Cmd가 함께 눌린 Tab·ESC·`/`는 무시. Ctrl/Cmd+S는 두 레이어 모두 가로채 `저장됨`.
- 키 판별은 `e.code`(`Tab`, `Escape`, `Slash`, `F10`) 우선. 캡처 단계 리스너 하나.
- 숨기는 순간 같은 프레임에 지울 것·보존할 것: UX §7-1 #2 그대로(드래그 중인 배치 범위도 취소).

### 9-2. 명령 이동 모드 (`/`)

1. 게임 화면에서 포커스가 글자 입력칸(검산 칸) 밖이면 `/`로 시작. 이름 상자 안에서도 시작한다(이름 상자는 좌표·범위만 받으므로 `/`는 입력값이 아님).
2. 포커스가 A6 순서의 첫 기능 버튼으로 간다. `←` `→` 이동(양 끝에서 멈춤), `Enter` 실행, `↓` 메뉴·드롭다운 열기, 목록 안 `↑` `↓` 이동·`Enter` 선택·`←` 닫기.
3. 끝내기: `/` 다시 누르기, 격자 클릭, 또는 기능 실행 뒤 자동으로 격자 선택으로 돌아감.
4. 비활성 버튼도 순서에 포함하고, `Enter`를 누르면 상태줄에 이유 1줄(`사용할 수 있는 검토 의견이 없습니다.` 등).
5. 포커스 표시는 2px 파랑 outline(§5-2 변경 4). 주황 링 금지.
6. 팝오버의 버튼 이동은 `←` `→`, 실행 `Enter`(UX §7-2).

### 9-3. 선택 → 반영 (UX §4-5 표 채택 + A3)

칸 클릭 = 선택 / 같은 칸 다시 클릭·더블클릭·Enter·✓ = 반영 / 이름 상자 좌표 + Enter = 즉시 반영 / 칸에서 `A~H`·`ㅁ ㅠ ㅊ ㅇ ㄷ ㄹ ㅎ ㅗ`·소문자 입력 = 이름 상자로 이동 후 이어서 입력 / 방향키 = 선택 이동(판 밖 불가). 서버 대기 중 선택 테두리는 회색, 클릭 무시. 중복은 `actionId`.

### 9-4. 배치 (UX §4-4 1~8 채택)

드래그 / 시작 칸 클릭 + Shift 클릭 / 이름 상자 범위 입력 + Enter·✓. 버튼은 배치 표 15행(B8). 모바일은 항목 탭 → 칸 탭 → `가로/세로` 토글, [자동 배치]를 가장 크게.

### 9-5. 메모·상태줄·토스트 시간

메모 = 2.5초 + 글자당 0.07초(3~7초), 창당 1개·전체 2개, 새 메모·다른 칸 선택 시 즉시 닫힘. 상태줄 웃음 문장 5초 후 중립 문장. 경보 토스트 최대 10초. 결과 생성 토스트는 열거나 숨길 때까지. 모두 등장·퇴장 즉시(페이드 없음).

### 9-6. 애니메이션

**없음.** 셸 안 `transition`·`animation`은 계산값 `none`이어야 한다. 카운트다운 숫자 바뀜이 유일한 움직임이다. 깜빡임·흔들림·소리·진동·Notification 금지.

### 9-7. 탭 제목·메타

UI §9 + 방향서 §8-2 그대로. 홈 `월마감`, 연습 `연습용_사본_v1`, 방 = 업종 파일명(`v{n}`), `title.absolute`, 제목 감시 후 재지정, 제목 알림 금지, noindex, `themeColor #F7F8FA`, OG 고정 1종. 아이콘은 §6-4.

### 9-8. 접근성

UX §7-2와 UI §10을 그대로 따르되, F10 언급은 모두 `/`로 읽는다. 격자 `role="grid"`, 셀 `aria-label`(`B7, 해당 없음`), 상태줄 `role="status"`, 경보 `role="alert"`, 메모 본문 `aria-live="off"`.

**G0-5 미리보기 묶음(D1 끝, 메인 세션이 PM에게 전달)**
- 스크린샷 7장: 3업종 × (게임 화면, 숨기기 시트) at 1366×768 + 모바일 390×844 게임 화면 1장. 게임 화면에는 상대 판에 `0`·`1`·종결, 내 판에 내 항목·취소선이 보이게 한다. 탭 줄과 탭 제목이 보이도록 브라우저 창째로 찍는다.
- 숨기기 전환 시간 p95(로컬 크롬 20회), "Tab 뒤 주황 링 없음" 자체 확인.
- PM은 게임을 모르는 3명에게 숨기기 시트 3장과 게임 화면 1장을 10초씩 보여 주고 "업무 시트로 보이는지" 묻는다. 지적이 나오면 D2~예비일에 반영한다.

**일정이 밀릴 때 줄이는 순서**(방향서 §12-5에 이어 붙임): ①~⑥ 방향서 그대로 → ⑦ 장식 탭 = 주 숨기기 시트 표시 → ⑧ 숨기기 시트 차트 클릭 선택 표시 생략. **줄이지 않는 것**: 숨기기, 숨기기 시트 3종, 검산, 도발, 결과 메모, 시말서 문구, 명령 이동 모드.
