# 좀비 터지면 — 서울 생존 시뮬레이션 (`/zombie`)

> 성세천하: 여제의 탄생 II 류 선택형 시나리오 게임을 **한국형 좀비 사태**로.
> 한국인들이 "좀비 터지면 너 어떻게 할 건데?"라며 노는 그 놀이를 그대로 게임으로.

## 1. 한 줄
토요일 오후 2시, 긴급재난문자가 울린다. 콩이(반려견)를 데려갈 것인가, 피 흘리는 옆집 아저씨에게 문을 열어줄 것인가 — 선택 하나로 운명이 갈리는 3일간의 서울 생존기.

## 2. 핵심 루프
상황(씬 삽화 + 본문 + 재난문자/카톡/속보/무전/전화 연출) → 선택지 2~4개 → 결과 문단 + 스탯 변화 → 다음 장면.

| 시스템 | 규칙 |
|---|---|
| 스탯 | 체력·보급·정신력 0~100. 체력 0 → `dead`, 정신력 0 → `breakdown` (엔진 강제) |
| 보급 소모 | 장면마다 −(2 + 동행 수). 못 채우면 굶주림: 체력 −8, 정신력 −3 |
| 감염 | 물리면 6장면 뒤 변이(`turned`). HUD에 남은 장면 표시. 치료 경로는 극히 드묾 |
| 아이템 16종 | 야구방망이·소화기·빠루·구급상자·차 키·무전기·보조배터리·손전등·방독면·따릉이·라면·소주·사료·완강기·기름통·군 통행증 |
| 동료 6 | 콩이(시작부터), 1203호 할머니, 고3 민준, 정지수 간호사, 배달 라이더 용석, 김 병장 |
| 조건부 결과 | 이전 선택·아이템·동료가 결과를 바꾼다 ("그때 챙긴 방망이가…") |
| 잠금 선택지 | 조건 불충족 시 "콩이가 곁에 있었다면…" 식 손글씨 힌트로 리플레이 유도 |
| 확률 | 상태에 저장된 시드로만 굴림 → 새로고침으로 재굴림 불가 |
| 생존자 유형 | 선택 태그(의리·냉정·돌격·신중·댕댕이·밈) 최다 → 엔딩 화면 공유용 유형 |

## 3. 구조 (5장, 67장면, 엔딩 14)
```
1장 긴급재난문자 (D+0 14:00~, 집)  — 재난문자, 방송사고, 베란다, 엄마 전화, 외시경 딜레마, 콩이 딜레마
   ├─ 2A 12층 농성 (첫날 밤)        — 정전, 윗집 고3, 옆집 할머니, 입주민 단톡방, 지하주차장, 화재
   └─ 2B 대피 행렬 (첫날 밤)        — 반려동물 금지 버스, 기침하는 승객, 버스 사고, 라이더, 편의점
3장 서울 한복판 (D+1)               — 이동수단 허브, 편의점 약탈 딜레마, 마트, 대학병원, 지하철 선로, 좀비 떼
4장 생존자들 (D+1밤~D+2)            — 대피소 몸수색, 배급 정치, 물린 동료, 약탈자 거래, 군 방송, ★콩이 재회
5장 탈출 (D+2밤~D+3 새벽)           — 한강대교→잠실 헬기 / 인천항 수송선 / 북한산 산악회
```
엔딩: 생존(마지막 헬기·수송선·북한산 산악회·12층의 왕·혼자 남은 자) / 특별(콩이와 나·마지막 선택·격리) / 감염 / 사망(사망·붕괴·라면·배신·한강대교).

## 4. 화면
- **타이틀**: 재난문자 카드 + 로고(Black And White Picture) + 이어하기/엔딩 도감
- **플레이**: 스티키 HUD(시각·장소·스탯 바·감염·동행) · 16:9 씬 액자(스캔라인·비네트·상태 효과) · 본문 · 선택지 / 결과 패널
- **지도**: 작전지도 풍 서울 약도(한강·강북/강남), 지나온 경로 붉은 점선, 먼 목적지(북한산?·인천항?·잠실?)만 안개 속 표시, 챕터 트랙, 생존 기록
- **엔딩**: 엔딩 씬 + 도장(생존/사망/감염/특별) · 에필로그 · 손글씨 한 줄 → **헌정 크레딧** → 생존 기록 보고서 · 공유 · 엔딩 도감
- **헌정**: 모든 엔딩에 "우리의 친구 김성준에게 바칩니다" + 사진 (`public/zombie/dedication.jpg`, EXIF 제거)

## 5. 비주얼
콘셉트 "긴급재난문자 × 생존자 수첩". 녹흑 어둠 `#07090A`, 재난문자 앰버 `#FFB020`, 체력 레드 `#FF4D5A`, 보급 블루 `#5DB2E3`, 정신력 바이올렛 `#C3A4FF`, 감염 라임 `#A3D13F`.
씬 28종은 SVG "시네마틱 실루엣 듀오톤" — 공용 프리미티브(`scenes/primitives.tsx`: 좀비 3포즈·사람 5포즈·콩이·아파트 동·스카이라인·연기·불·차)로 일관성 유지. 외부 이미지 0, 애니메이션은 CSS(`zs-*`), `prefers-reduced-motion` 준수.

## 6. 기술
- 라우트 `src/app/zombie/` (layout·page·components·scenes·lib) — 공유 파일(root layout/globals.css/tailwind) **무수정**
- 엔진 `src/lib/zombie/engine.ts` 순수 함수, 콘텐츠 `src/lib/zombie/content/*.ts`(타입 체크되는 TS 데이터), 계약 `contract.ts`, 검증 `validate.ts`
- 저장: localStorage (`zb:run:v1`, `zb:endings:v1`), 실패해도 게임 진행 가능. 서버·DB·env 없음
- OG: `public/zombie/og.jpg` (1200×630 정적)
