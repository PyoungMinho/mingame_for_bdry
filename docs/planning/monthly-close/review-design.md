## 판정: 조건부 승인

위장 품질은 기대 이상이다. 게임 화면 1장과 숨기기 시트 3장 모두 "업무 표"로 읽히고, 녹색·움직임·손 모양 커서·네이티브 UI·상표가 0이다. 웃음 문구도 결정대로 들어갔다.
다만 **같은 CSS 원인 하나 때문에 기본(파랑) 버튼 글자와 결재 경보 토스트 글자가 거의 안 보인다(대비 2.3:1, 1.2:1).** 그 밖에 오답 메모 미표시, 모바일 홈·결과 문서 깨짐, 노트북 높이에서 결과 작업 줄이 화면 밖에 있는 문제가 있다. 아래 **필수 5건(M1~M5)**을 고치고 해당 화면을 다시 캡처하면 승인으로 바꾼다. 5건 모두 CSS·배치 수준이고 게임 로직은 건드리지 않는다.

## 2. 수정 요청

### 출시 전 필수 (5건 — 모두 CSS·배치 수준)

**M1. 기본 버튼·경보 토스트 글자색이 덮어써짐 (대비 실패)**
- 원인: `monthly-close.css` 224행 `.mc-root button { font: inherit; color: inherit; }`(명시도 0,1,1)가 `.mc-btn { color:#fff }`·`.mc-toast { color: var(--mc-toast-fg) }`(0,1,0)를 이긴다.
- 영향(실측): 기본 버튼 글자 `#1F2328` / 바탕 `#2F5E8E` = **2.34:1**. 홈 [공유 문서 만들기]·첫 방문 [박대리와 연습 2분], 상단바 [공유], 입장 대화상자 [열기], 예외 대화상자 [새 문서 만들기], [배치 완료], [v8로 저장], 모바일 [반영]. 결재 경보 토스트(`<button class="mc-toast mc-toast--alarm">`)는 `#1F2328` / `#2B2F36` = **약 1.2:1**로 글자가 사실상 안 보인다(`out/prac-alarm.png`). 같은 원인으로 `.mc-tab`·`.mc-tool`·`.mc-toast__link` 등의 지정 색도 무시되고 있다.
- 처리 방향: 초기화 규칙의 명시도를 낮춘다(예: `:where(.mc-root) button { font: inherit; color: inherit; }`). 표적 덮어쓰기로 갈 경우 비활성 기본 버튼(`#9AA1A9` / `#E3E5E8`)까지 흰 글자가 되지 않게 주의.
- 합격 기준: 기본 버튼 흰 글자(6.7:1), 경보 토스트 본문·`[Tab]` 칩 흰 글자, 비활성 기본 버튼은 지금 모양 유지, 시트 탭·도구줄은 UI §2 지정 색. 홈·입장 대화상자·경보·배치·결과 탭 재캡처.

**M2. 검산 오답 메모가 나오지 않음**
- 원인: `_screens/Battle.tsx`가 오답 메모를 `H13`에 붙이는데 H13은 E13:H13 병합 안이라 DOM에 칸이 없다. 실측: 오답 후 0.15/0.6/1.5초 모두 메모 0개(`out/wrong-memo.png`, `log-wrong.json`). `quizWrong` 3줄("소수점 이하는 반올림하지 않습니다." 등)이 한 번도 보이지 않는다.
- 처리: 메모 기준 칸을 입력 병합의 시작 칸 **B13**으로(병합 오른쪽 위 = 원래 의도한 D13 모서리). 디자인 §4-3의 "D13"도 병합 안이라 내 사양 오류 — **"입력 병합(B13:D13) 오른쪽 위"로 정정한다.**

**M3. 홈 360px 레이아웃 겹침**
- `Home.tsx`의 인라인 `gridTemplateColumns: 'minmax(0,1fr) minmax(0,1fr)'`가 모바일에서도 2단이다. 공유 텍스트 5줄째가 홈 주소라 카톡으로 받은 사람이 휴대폰으로 처음 보는 화면이 여기다.
- 처리: 720px 미만에서 1단 쌓기, 좌우 여백 16px(UI §8 "모바일은 세로로 쌓고"). 순서: 새 문서 → 안내 → 문서 번호 → 최근 문서 → 연습.

**M4. 모바일 결과 문서 잘림·겹침**
- 1024px 미만에서 문서가 PC 위치(x=104)에서 시작해 `calc(100vw - 16px)` 폭이 화면 밖으로 나가고, 절대 위치 결재란이 제목 "포상 품의서"를 덮는다. 작업 줄 버튼 글자도 한쪽으로 치우친다.
- 처리(UI §7-4 그대로): 왼쪽 8px에서 시작, 폭 `calc(100vw - 16px)`, 결재란은 제목 아래 오른쪽 정렬(칸 폭 56), 라벨 칸 64 + 값 칸 가변, 작업 줄은 한 줄에 하나·높이 44·글자 가운데.

**M5. 노트북 높이에서 결과 작업 줄이 화면 밖**
