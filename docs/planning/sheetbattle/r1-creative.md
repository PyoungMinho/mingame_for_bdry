# 기획 회의 ROUND 1 — 창의팀원 발산 (sheetbattle)

주제: 엑셀풍 화면에서 동료와 1대1로 하는 좌표 해전 (셀 주소 = 좌표, 업무 중 몰래 하는 웹 게임)
작성: @창의팀원 (Haiku, R1)
제약 반영: (a) 힌트 제도 필수 (b) ESC 위장 시트 여러 개, 업무별, 오래 봐도 티 안 나게

---

## 아이디어 브레인스토밍

### 축 1. 해전 규칙을 스프레드시트답게 비틀기

1. **배 = 셀 범위** — 배는 가로/세로로 이어진 셀 블록. 길이 2~5칸. 병합된 셀 한 덩어리는 "대형 배(보고서 표)"로 취급.
2. **시트 탭 = 함대 분산** — 배를 탭 여러 장에 흩어 숨긴다. 탭 3장 중 2장을 맞혀야 침몰. 탭 이름이 곧 위장 (예: "1분기", "비고", "참고").
3. **숨긴 행/열 함정** — 배를 숨긴 행에 두되, 상대가 "행 숨기기 취소"로 찾을 수 있게 열어 둠. 숨긴 행을 드러내는 것 자체가 탐색 행동이 되어 긴장감을 준다.
4. **필터 = 공격 결과 표시** — 필터 기능으로 "피격"만 골라 보는 것이 명중 확인. 자연스러운 업무 조작처럼 보인다.
5. **조건부 서식 = 피격 색칠** — 맞은 칸은 빨강/노랑 조건부 서식, 빗나간 칸은 회색. 엑셀 사용자에게 가장 자연스러운 "표시" 방식.
6. **정렬 셔플** — 턴마다 좌표 열을 정렬하면 배 위치가 바뀐다 (실수로 정렬하면 본인 배가 흩어짐 = 리스크).
7. **차트 = 전황판** — 명중률 막대 차트, 남은 배 게이지를 꺾은선으로. 진행 상황이 차트로 보인다.
8. **피벗 테이블 = 함대 요약** — 행은 함종, 값은 생존 칸 수. 침몰 여부가 피벗에서 드러남.
9. **셀 메모(주석) = 비밀 메시지** — 특정 셀 주석에 힌트를 숨겨 두고, 그 셀에 마우스를 올리면 보이는 식.
10. **이름 정의(Named Range) = 작전명** — "작전_북쪽" 같은 이름으로 배 범위를 지정. 이름 관리자에서 본인 것만 보임.
11. **#REF! 오류 = 힌트 소진** — 힌트를 다 쓰면 셀에 #REF!가 뜬다. 오류처럼 보이지만 게임 상태 표시.
12. **시트 보호 = 함대 잠금** — 배치 완료 후 시트 보호. 보호 해제는 "비밀번호 없음" 버튼 하나로 통제 (재배치 금지).

### 축 2. 힌트 제도 (PM 필수 요구)

13. **열 카운트 힌트 `=COUNTIF(B1:B10,"배")`** — 해당 열에 배 칸이 몇 개인지. 결과 숫자 하나가 힌트. 셀 수식 입력 자체가 위장.
14. **행 합계 힌트 `=SUM(...)`** — 행마다 배 칸 수를 합산한 숫자를 받는다. 행과 열을 교차 확인하면 좌표 범위가 좁혀진다.
15. **인접 판정 힌트 `=OR(...)`** — "B7 주변 1칸 안에 배가 있나?" → TRUE/FALSE. 대략적 위치 감지기.
16. **방향 힌트 `=IF(...)`** — 배가 가로인지 세로인지 판정. 2칸짜리 배 탐색에 특히 유용.
17. **힌트 얻는 법 A: 포인트 소모** — 명중 1회 = 포인트 1. 포인트 5 모아 힌트 1개 구매 (수식 셀 하나 잠금 해제 식).
18. **힌트 얻는 법 B: 상대 승인 요청** — "데이터 검토 요청" 버튼. 상대가 수락해야 힌트 제공. 상대가 "네, 확인했습니다" 답하면 힌트 1개 (상대 공격 턴 한 번 양보 비용).
19. **힌트 얻는 법 C: 정식 결재 프로세스** — 힌트 요청 → 상대 결재 → 승인되면 결과 셀 노출. 결재 문구가 업무처럼 보임.
20. **힌트 노이즈 옵션** — 난이도 "보고서 오차 ±1" 모드. 숫자가 맞지 않을 수 있어 해석이 필요.
21. **힌트 횟수 제한** — 게임당 3개, 또는 턴당 1개. 아껴 쓰는 재미.
22. **숨은 힌트 = 주석 수식** — 셀 메모에 "이 행의 합계는 3" 같은 텍스트를 몰래 넣어주는 방식 (비용 0, 눈치 게임).

### 축 3. 업무별 위장 시트 (ESC 전환용)

23. **회계 — "3분기 예산 집행표"**: 항목명·금액 열. 금액 셀 하나하나가 좌표. 합계 행이 실제로 맞아떨어지는 것처럼 보임 (합계 계산 수식이 진짜).
24. **인사 — "연차 사용 현황"**: 이름 대신 부서 코드 + 날짜 열. 좌표 격자가 달력처럼 보임. 연차 "사용" 색칠 = 피격 색칠과 같은 로직으로 자연스러움.
25. **영업 — "월별 리드 관리"**: 고객사명, 단계(드롭다운: 신규/미팅/제안/보류). 드롭다운 값이 상태 표시로 쓰임.
26. **구매 — "발주 내역 (품목 코드 A1~)"**: 품목 코드가 좌표. 수량 열의 "0"이 빈칸 역할.
27. **개발 — "스프린트 번다운"**: 티켓 번호 열 + 스토리 포인트. 차트 한 장이 자연스럽게 붙음.
28. **재고 — "창고 실사 체크표"**: 선반 번호 × 층. 실사 완료 체크(✓) = 피격 표시.
29. **근무표 — "주간 교대 시프트"**: 요일 × 시간대 격자. 가장 긴 이름과 셀 병합이 자연스러운 위장.
30. **회의실 — "회의실 예약표"**: 시간 × 방 번호. 예약된 칸 = 배. 좌표 해전 그 자체로 위장력 최상. (축 1 #1과 시너지)
31. **식당 — "점심 메뉴 투표"**: 메뉴 × 요일. 투표 수 숫자 = 힌트 위장.
32. **Ctrl+S 가짜 저장** — 저장 시 "자동 저장됨" 토스트, 아이콘 회전. 실제로는 게임 상태 저장.

오래 봐도 티 안 나게 하는 장치:

33. **숫자 미세 변동** — 1~2분마다 환율/재고 숫자 소수점 아래만 바뀜. 살아 있는 데이터처럼 보임. (게임 판에는 영향 없음)
34. **커서 깜빡임 + 셀 선택 이동** — 커서가 가끔 옆 셀로 이동해 "작업 중" 느낌.
35. **스크롤 고정 헤더** — 헤더 행 고정 + 우측 하단 "준비" 상태 텍스트 + 계산 중 "계산 중..." 아주 짧게 노출.
36. **보고서 마감 시계** — 상단 "마감까지 2시간 14분" 카운트다운. 업무 긴박감을 주고 실제로는 게임 타이머.
37. **ESC 전환 즉시** — 실제 스프레드시트 앱처럼 전환 딜레이 없음. 전환 시 탭 제목만 바뀜.
38. **툴팁 노이즈** — 셀 위에 마우스 올리면 "이 셀은 잠겨 있습니다" 같은 가짜 툴팁 (전부 게임 로직과 무관).

### 축 4. 동료 끌어들이기

39. **초대 링크 = "공유 문서 링크"** — 링크 자체가 `/sheet/...` 형태. 사내 메신저에 붙여도 업무 문서처럼 보임.
40. **부서 대항 "주간 승률 시트"** — 팀 공유 시트 한 장에 승률이 자동 집계. 팀장이 "이거 우리 팀 실적표인가?" 하고 궁금해하게 만드는 것도 바이럴.
41. **전국 지사 대항** — 지역 코드 셀(서울/부산/...)에 승률이 쌓이는 전국 집계판. PM이 좋아하는 전국 대항 구조 그대로.
42. **점심 내기 자동 정산** — 진 사람이 커피/점심 한 번 정산. 결과 셀에 "오늘 쏘기" 표기. (※ 기존 커피볼 프로젝트와 겹치므로 배타 아닌 조합 검토 필요)
43. **익명 로비 6자리 코드** — 사내 잡담방에 코드만 던지면 참여. 회의실 번호처럼 보이는 코드.
44. **결과 이미지 공유** — 게임 후 "결과 공유" 버튼으로 팀 채널에 피격 현황 이미지만 전송 (승패 표 형태).

### 축 5. 혼자 할 때 재미

45. **컴퓨터 대전 3단계** — 쉬움(랜덤 사격), 보통(인접 탐색), 어려움(확률 히트맵 사격). 히트맵은 조건부 서식 색 농도로 보여서 "AI가 계산 중" 같은 연출.
46. **데일리 보고서 퍼즐** — 하루 1개 고정 배치. 전국 같은 배치로 풀고 시트에 점수 기록 (전국 순위 집계 가능).
47. **타임어택 마감 모드** — "오후 5시 전에 함대 침몰시키기". 퇴근 시간 맞춤.
48. **고스트 리플레이** — 어제 최고 기록의 공격 순서를 셀 하나씩 재생. 상대 없이도 기록 경쟁.
49. **퍼즐 모드: 힌트만으로 풀기** — 배치는 고정, 힌트 수식만 써서 몇 턴 안에 맞히기.

### 축 6. 다시 오게 만드는 장치

50. **연승 스트릭 셀** — "현재 연승 3" 같은 셀이 시트 상단에 고정. 끊기기 싫어짐.
51. **월말 보고서 자동 생성** — 한 달 전적을 "월간 보고서" 시트로 자동 정리. 공유 가능 이미지 제공.
52. **분기 시즌** — 회계 분기에 맞춘 3개월 시즌. 시즌 끝 "3분기 결산" 시트 발행.
53. **업무 시간 연동** — 평일 9~18시만 "정상 업무 모드". 업무 끝나면 시트가 "퇴근 전 저장" 메시지로 닫힘 (쉬는 날엔 잠김 해제 옵션).
54. **알림 없이 탭 제목 신호** — 알림은 일절 보내지 않는다. 대신 탭 제목에 "미확인 셀 1개" 같은 살짝 신호.

### 영감 메모

- 핵심 위장 원리: **"셀 하나 = 좌표 = 숫자 한 칸"**. 스프레드시트에서 숫자 한 칸은 평범하다. 그래서 좌표 해전이 업무 문서처럼 보일 수 있다.
- 두 사람이 "같은 보고서를 보는" 조건을 맞추려면, 양쪽 화면이 **완전히 같은 격자** + 상대 배만 숨겨진 상태여야 한다. 공격 결과(피격/빗나감)만 같은 셀에 공통 표시. 조건부 서식 하나로 구현 가능.
- 회의실 예약표 위장이 가장 강하다. 시간×방 격자 = 좌표 판, 예약 칸 = 배. 업무 동선과 가장 가깝다.
- "힌트 = 수식 결과"는 게임의 재미이자 위장의 핵심. 수식 결과가 숫자 하나로만 나오도록 설계하면 사무실 PC에서 수식을 쳐도 자연스럽다.
- 텐션 포인트: 화면 우하단 "마감 카운트다운" + "상사 접근 시 ESC" 같은 고전적 긴장 장치는 다시 오게 만드는 힘이 있다.
- 주의(판단은 PM): 사내 기기에서 업무 외 프로그램 사용은 회사 정책 위반 소지가 있다. 사내 메신저 링크 배포는 PM이 정책 확인 후 결정 권장.
- 기존 프로젝트와 겹침: 커피볼(슬랙 내기), 목격자/거짓말 게임 등 직장인 유머 라인과 톤이 맞는다. 점심 내기 축은 커피볼과 통합 검토 가능.
