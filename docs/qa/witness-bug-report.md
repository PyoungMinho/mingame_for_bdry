## BUG-W01: 언마운트된 화면이 1초 뒤 meta 를 통째로 덮어써서 도감·플레이 횟수가 사라짐

### 심각도: Low(실사용 노출은 드묾 · 데이터 손실 성격) — **수정함**
### 재현 스텝
1. 증언 화면에서 대사를 읽어요(읽음 기록이 1초 지연 저장 타이머에 걸려요).
2. 1초 안에 앱이 언마운트돼요(에러 경계 재마운트, 다른 라우트로 이동, 테스트의 cleanup).
3. 그사이 다른 인스턴스가 엔딩을 기록해요.
### 기대 결과
새로 기록된 엔딩·플레이 횟수가 남아야 해요.
### 실제 결과
1초 뒤 언마운트된 인스턴스의 `flushRead` 가 자기 meta 스냅샷을 통째로 저장해요. 엔딩 8종 화면 테스트에서 「수사 배제」 기록이 지워졌어요(`expected ['perfect','hidden'] to include 'excluded'`).
### 원인 · 수정
`useWitnessGame` 의 읽음 기록 타이머를 언마운트 때 지우지 않았어요. 언마운트 정리에서 남은 기록을 즉시 저장하고 타이머를 지우도록 바꿨어요(`src/app/witness/lib/useWitnessGame.ts`, 8줄).
### 회귀
`witness.endings.test.tsx` › "BUG-W01 회귀" — 수정을 되돌리면 실패하고(`expected [] to deeply equal ['timeout']`) 수정하면 통과하는 것을 확인했어요. 엔딩 8종 테스트도 같은 방식으로 확인했어요.
### 영향 범위
meta(도감·업적·플레이 횟수·읽은 대사·설정)만 해당해요. 한 탭에서 정상적으로 하는 플레이에는 영향이 없어요.

## BUG-W02: 좁은 화면에서 HUD 수첩 버튼이 화면 밖으로 밀려남(320) · HUD 버튼이 44px 아래로 줄어듦(375)

### 심각도: High(320) / Medium(360~375) — **수정함**
### 재현 스텝
1. 320×568 로 /witness 에서 장소 조사나 증언 화면에 들어가요.
2. 오른쪽 위 수첩 버튼을 찾아요.
### 기대 결과
디자인 D02 compact HUD `[< 44][시계 칩][한결+신뢰][★ n/3][수첩 44]`, 합계 약 332px 이 한 줄에 들어가야 해요.
### 실제 결과
- 320: 수첩 버튼이 x=321(폭 20)에 그려져 **화면 밖으로 사라져요**. 나가기 버튼은 22px 이에요. 허브 [설정] 버튼은 20px 에 2px 가 잘려요.
- 375: 나가기·수첩 버튼이 32~37px 로 줄어요.
- 원인: compact 줄 실제 폭이 약 390px 이에요(★ 아이콘 3개 = 94px, 신뢰 묶음 122px). 여기에 `.wt-iconbtn` 이 flex 축소를 허용했어요. 증거 시트의 「자세히 보기」(36 → 22px)도 같은 원인이에요.
### 수정(`witness.css` 끝, `.wt-shell` 스코프)
- `.wt-iconbtn { flex: none }` — 아이콘 버튼은 줄지 않아요.
- compact ★ 게이지는 디자인 D02 대로 **별 아이콘 1개 + 숫자**로 바꿨어요. 허브는 그대로 3개예요.
- 389px 이하: compact 간격과 신뢰 칸을 줄여요. 373px 이하(360 안드로이드 포함): 허브 HUD 간격과 신뢰 칸을 줄여요. 359px 이하: compact 는 한결 얼굴을 숨기고(신뢰 칸은 그대로 보여요), 허브는 남은 행동 숫자 칩(핍·시계와 같은 정보)과 ★ 아이콘 2개를 숨겨요.
### 재검증
320 · 360 · 375 · 390 · 414 × (증언, 허브, ★ 5개 대질, 행동 1 허브)에서 HUD 버튼이 모두 44px 이고 화면 안에 있어요. 줄 넘침은 0이에요. 스크린샷 138장의 지표도 다시 쟀어요.
### 영향 범위
HUD 모양이 바뀌어요: 375 에서 compact ★ 아이콘 3 → 1, 320 에서 한결 얼굴과 허브 숫자 칩이 숨어요. **PM·디자인 확인 권장**이에요(디자인 D02 원안과는 일치해요).

## BUG-W03: ★ 게이지 「★3 +2」가 두 줄로 접혀 알약 밖으로 잘림

### 심각도: Low — **수정함**
결정적 모순을 4개 이상 깨면 compact HUD 의 「★3 +2」가 「★3 / +2」 두 줄이 되고, 윗줄이 알약 위로 잘려요(13b-confront). `white-space: nowrap` 을 넣고 BUG-W02 의 폭 정리로 해결했어요. 「신뢰 n」이 「신뢰 / 5」로 접히던 것(허브 320)도 같이 고쳤어요.

## BUG-W04: ★ 돌파 흔들림 때 문서에 순간 가로 스크롤(377~379px)

### 심각도: Low — **수정함**
`.wt-screen[data-shake]` 의 translateX 가 뷰포트 밖으로 1~4px 나가요. 그 순간 iOS 에서 화면이 옆으로 밀릴 수 있어요. `.wt-shell { overflow-x: clip }` 으로 쉘 가장자리(= 뷰포트)에서 잘랐어요. clip 은 스크롤 컨테이너를 만들지 않아서 sticky 탭에 영향이 없어요. 재측정 결과 가로 스크롤은 0이에요.

## BUG-W05: 증거 시트 빈 슬롯 라벨 「B」 대비 4.13:1(< 4.5)

### 심각도: Low — **수정함**
12px 글자가 반투명 `line-3` 바탕 위에 있었어요. `muted` 바탕으로 바꿔 ink-dark 기준 약 6.3:1 이 됐어요. 재측정 결과 켜진 글자 중 대비 미달은 0개예요.

## BUG-W06: 플레이 중에 저장이 실패하면 알림이 없음
### 심각도: Low
### 재현 스텝
1. 이어하기로 허브에 들어가요.
2. localStorage 쓰기가 실패하게 해요(용량 초과).
3. 장소에 들어가요.
### 기대 결과

## BUG-W09: 마지막 줄에서 0.45초 넘게 누른 '느린 탭'이 먹혀서 대사가 안 닫힘

### 심각도: Low — **수정함**
### 재현 스텝
1. 375×812, 아무 대사나 마지막 줄까지 넘겨요(한 줄짜리 반응이면 첫 줄이 곧 마지막 줄이에요).
2. 대사창을 0.6초 동안 눌렀다 떼요(천천히 누르는 사람의 보통 탭).
### 기대 결과
탭과 같게 대사가 닫히고 다음 단계로 넘어가야 해요.
### 실제 결과
아무 일도 없어요. 한 번 더 짧게 눌러야 닫혀요(헤드리스 Chrome 터치: 600ms → 대사 그대로, 120ms → 닫힘).
### 원인 · 수정
UX 수정 ⑥의 길게 누르기는 0.45초가 지나면 '길게 누름'으로 보고, 뗄 때 따라오는 클릭을 무조건 삼켰어요. 마지막 줄에서는 연속 넘김이 아무것도 넘기지 못하는데도 클릭을 삼켜서 탭이 사라졌어요. 길게 누르는 동안 실제로 넘긴(또는 완성한) 줄 수를 세고, 0이면 클릭을 보통 탭으로 처리하게 바꿨어요(`components/DialogueBox.tsx`, 몇 줄). 연속 넘김으로 마지막 줄에 닿은 뒤 떼면 닫지 않는 원래 설계는 그대로예요.
### 회귀
새 파일 `src/app/witness/witness.polish.test.tsx` 4개 — 수정을 되돌리면 2개가 실패하고(`expected "spy" to be called 1 times, but got 0 times`) 수정하면 4개 모두 통과하는 걸 확인했어요. 기존 UX 테스트 23개도 통과해요. 브라우저에서도 다시 확인했어요: 600ms → 닫힘, 1.7초 연속 넘김 → 마지막 줄에서 멈추고 뗄 때 안 닫힘.
### 영향 범위
대사창(DialogueBox)을 쓰는 모든 화면이에요(인트로·조사·증언·판정·엔딩). 짧은 탭과 연속 넘김은 그대로예요.
