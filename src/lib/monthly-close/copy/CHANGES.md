# 문구 팩 변경 기록 (옮기기만, 새 문구 금지 — 디자인 최종 E1)

원문 = UX §9 + §2-5 + 디자인 최종 §4-2·§6-2·§8. 길이 초과로 후보를 바꾼 곳: **없음**(4개 팩 모두 동결 스키마 통과).

## 원문 수정표 반영 (디자인 §8-2)
- 시말서 A 3업종: "경위서를 제출합니다" → "시말서를 제출합니다". `{배}을(를)` → `{배:을}` (인사 시말서 A는 원문이 `{배} 처리를`이라 `{배}` 유지).
- 반려(명중) 엉뚱한 문구 6줄: 회계 5·6, 영업 4·6, 인사 4·5를 §8-2 표 그대로.
- 검산: 부가세 머리글 `[구분, 공급가]`, A13 라벨 `합계/부가세/차액(인사 차이)` + `inputHint` + `unit`(인사 합계 null).
- 상태줄 `selected` = `{t} · {c} 선택됨 · Enter로 반영`, 홈 안내 F10 → `/` 키.
- 탭 이름: 디자인 B6(회계 월결산/손익/비고, 영업 리드/채널별/목표, 인사 현황/팀별/비고) — UX §9의 탭 이름은 쓰지 않음.

## 원문에 없어서 채운 곳 (판단 필요하면 알려 주세요)
1. `endReasons.draw`: 원문 표에 동시 종결 문구가 없어 `sunk2`와 같은 "모든 항목이 종결되어 마감되었습니다."를 재사용.
2. `disguise.note`(30행 비고): 원문 없음 → 같은 업종 `deco.memos[0]`(디자인 §8-5, 등급 0)를 재사용.
3. 인사 숨기기 시트 행 이름(B열 부문): 원문은 팀 코드만 있어 평범한 팀 이름(총무팀·인사팀·재무팀·구매팀·법무팀·홍보팀 / 영업1팀·영업2팀·기획팀·개발팀·품질팀)으로 채움. 사람 이름·평가 없음.
4. 영업 숨기기 시트 A열 `구분` 값 = 묶음 이름(온라인/오프라인), 소계 라벨 `소계`, 합계 라벨 `합계`(UI §4-1 행 이름).
5. 상태줄 추가 키(스키마 catchall): `oppFirst`("{상대}님이 먼저 편집합니다.", UX §4-5), `autoPlacedBtn`("자동 배치되었습니다.", UX §4-4). 연습 코치 12번째 줄 "연습: 아래 시트 탭 클릭"(UX §2-5 컷6 회색 보조).
6. `legal`은 Microsoft·Google 문장만(예외 필드). 같은 홈 고지의 "회사 규정 확인은 본인 몫…"은 `copy/ui-text.ts`.
7. 버튼·메뉴·홈 안내 등 고정 라벨은 스키마에 필드가 없어 `copy/ui-text.ts`에 모음(출처: UX §4, 디자인 §4-1). copy.test.ts의 금지어 검사는 JSON만 본다.
8. 시말서/품의서 제목의 공백: `포상 품의서`·`공동 경위서`(C19 본문 표기 그대로, 스키마 6자 이내).
